# 分数 → 组合：2021 扫描、2023-2026 quasi-holdout，以及 softmax 在股票数据上的训练方法

**日期**：2026-10-19  
**样本**：A 股 2010-01-04 至 2026-09-28，点时股票池（过去 60 日成交额前 1000、上市满 252 日、剔除 ST/停牌），决策间隔 21 个交易日  
**fold 0**：训练 2013-2018，验证 2019-2020，测试 2021-01-04 至 2021-12-31（未污染）  
**最终 quasi-holdout**：训练 2013-2020（93 个决策），验证 2021-2022（24 个），测试 2023-01-03 至 2026-09-28（42 个决策 / 906 个交易日；2023+ 因子层被早前研究污染，不是干净 OOS）  
**代码**：quant_factor_ashare/ml_policy/  
**前半部分没有改网络、没有改损失、没有重训模型**：只把已经训练好的三颗种子的 logits 导出来，单独扫“分数 → 权重”这一步；硬引擎只读同一批分数。**P1.7 是唯一一次固定配方的重训**，测试期不调参。

---

## 0. 一句话结论

**分数里有信息，但 2023-2026 的最终 quasi-holdout 说明：这点信息还不足以变成可交易的 long-only 组合；2021 的 +20.3% 是 regime-specific，不能外推。**

- 2021 fold 0（3% cap、25bp）：同一批分数，**等权 top500 +20.3% / Sharpe 1.16 / maxDD -9.0%**；模型自己的 900 路 softmax **+15.1% / .86**；全池等权 **+14.3% / .79**。映射层当时确实丢掉了约 5 个点。
- 但把同一 p1 配方改成 train 2013-2020 / valid 2021-2022 / test 2023-2026 后：policy softmax **-0.12% / Sharpe -0.005**，top500 **+2.08% / .087**，等权 top decile **-4.11%**，市值 top decile **+3.90%**，全池等权 **+3.78%**，而**全池市值加权 +7.41% / .475 / maxDD -18.56%**。六种读出相对 vw_all 的 alpha 全是负点估计（-3.76% 到 -12.21%/yr，t -0.48 到 -1.50）；相对等权也只有市值 top decile 一个正点估计（+1.78%，t .21）。**没有任何策略跑赢被动市值加权。**
- 分数层不是零：修正 IC 网格错位后，2023-2026 ensemble test IC **+0.0369**（42 个决策）；分年 +0.071 / +0.081 / **-0.062** / +0.078。2025 符号反转，long-short top-bottom 全期 +1.24%/21d（年化 +14.9%，naive t .85），有方向、没有统计显著性。
- 2022 fold 1 的 long-only 亏损仍是 beta：top500 **-24.8%** vs 全池等权 **-25.5%**，对冲后 alpha 仅 -1.1%。**2021 是 alpha 年，2022 是 beta 年，2023-2026 是弱信号 + 因子反转 + 成本年。**
- 文献里 softmax 不是不能用，而是**几乎没人对全市场 900 只股票做一路 softmax 再用一个组合收益去训练**。成功案例是逐股标签 + 月频 decile 组合，或短名单内 softmax/ListNet。我们的实验与这一点一致：**输出层不是瓶颈，监督信号和可交易映射才是。**

## 1. 我们到底做了什么（先把链路说清楚）

### 1.1 网络

qlp/policy.py:78-104：

- 每只股票在每个决策日一行 **70 维**输入：10 个价量因子的截面 rank + 10 个缺失标记 + 邻居当期 20 列 + 邻居滞后 20 列 + 图有效性 1 列 + 市场状态 6 列 + 账户状态 3 列。
- 共享 MLP：70 → 32 → 16 → 1，ReLU + Dropout(0.10)，共 **2818 个参数**。
- 输出标量 z_i，再除以温度 T；末尾接一个可学习的 cash_logit，在 **股票 + 现金** 上做 softmax：

  z = encoder(x).squeeze(-1) / temperature  
  full = torch.cat([z, cash_logit])  
  w = torch.softmax(full, dim=0)
- 训练时温度从 1.0 退火到 0.1；验证集早停选中的 epoch 实际温度是 0.58 / 0.72 / 0.77（三颗种子），不是 0.1。

### 1.2 训练目标

run_policy.py:163-181、qlp/policy.py:179-197：

```
gross = sum(w_i * r_i)
cost  = 25bp * (buys + drops)
loss  = -(gross - cost)
```

每个决策日只给模型**一个组合收益数字**；900 只股票共享这一个标量。训练集 fold 0 只有 **70 个决策日**，验证集 **24 个**。这是“有效样本量”问题的根源，也是上一轮对话里已经指出的。

### 1.3 三个结构性弱点（这次扫描进一步确认）

1. **softmax 的作用域是全部股票**：~900 路竞争同一个归一化常数；3% 上限再把大多数权重压到 0.1% 附近。模型即使想表达“这只特别好”，也被摊平。
2. **没有逐股监督**：组合收益对个股的梯度是 w_i * (r_i - r_p)，而 w_i ~ 0.1%；相比 GKX 那种每只股票一个标签的损失，信用分配小三个数量级。
3. **账户状态是常数**：qlp/dataset.py:130-134 的 build_state(slot, cash_w=0, n_hold=0) 在训练时永远传 0；模型看不到自己上一期持有什么，也没有 w\_{i,t-1} 输入。EIIE 明确把上一期权重塞进投票层之前，我们这里没有。这直接放大了换手。

### 2.2 怎么读这张表

**第一，映射层确实丢了钱。**  
top500 比本次复跑的政策网络多 **+5.2 个点**，比全池等权多 **+6.0 个点**；政策网络只比全池等权多 **+0.8 个点**。同一批分数，换一个读出规则，差 5 个点——这不是“数据没信息”，是“信息没进权重”。

> 口径提醒：上一轮 p1 报告写的是 +17.9%，本次同一组种子复跑的政策网络是 +15.1%，差 2.8 个点（重训/执行路径差异）。如果你拿 +17.9% 做参照，top500 的增量是 +2.4 个点；如果拿本次同表 policy 做参照，增量是 +5.2 个点。**两种参照都指向 top500 更好，但不要把 +17.9 和 +15.1 混着比。**

**第二，最优区间是 300-500，不是 30-100。**  
CAGR 从 top30 的 +6.4% 升到 top200 的 +18.4%、top300 的 +20.7%、top500 的 +20.3%，然后在 top100 掉到 +11.8%。这不是单调的“越集中越好”，而是一个**宽顶部**。top500 的 Sharpe、回撤、换手、成本都优于 top300，风险调整后更好；top300 的 CAGR 略高，但回撤和成本更大。**如果只能选一个，top500 更稳；top300 是激进版。**

**第三，top100 是“看起来合理、实际最差”的区间。**  
top100 的 CAGR +11.8%，低于 top200/300/500，也低于政策网络；换手 2313%、成本 420bp 是 topN 里最高（softmax top100 更高，2369%/422bp）。原因有两个：

- 分数最顶端的 100 只噪声很大；三颗种子的**快速核算** CAGR 分别是 **6.7% / 17.9% / 24.4%**，跨度 17.7 个点；top300 是 **16.4% / 20.3% / 18.7%**，跨度 3.9 个点。
- 100 只的组合残差分散不足，换手又高，成本吃掉 alpha。

**第四，softmax 在短名单内也没有优势。**  
softmax top100（+8.9%）低于等权 top100（+11.8%）；softmax top100 T=0.03 的 3% 上限把权重压得很尖，实际只投出很少。**在这批分数上，短名单内“等权”比“softmax 加权”更稳。** 这不是说 softmax 无用，而是说：**softmax 只应作为“在已经选中的名单内分配”的工具，不应作为“从 900 只里选谁”的工具。**

**第五，现金节点是拖累。**  
政策网络 +15.1%，去掉现金节点的股票 only softmax +17.8%，差 2.7 个点。2021 年现金收益为 0，模型却平均留 6.6% 现金；这个现金配置在训练集（2013-2018）可能合理，在 2021 的上涨市里是纯拖累。**要么给现金真实的无风险收益，要么在牛市/高置信度时约束现金权重。**

**第六，全池等权 +14.3% 与旧 baseline beq 的 +14.3% 完全对上**，说明硬引擎口径是可靠的；快速核算表里的 ew_all +3.7% 是 21 日前向收益在缺失价格上按 0 处理造成的向下偏差，不能拿来做绝对水平比较。

### 2.3 随机对照：不是“随便选一堆票”

同一批日期、同样持仓数、随机选股、等权、同成本，20 次抽样：

| 随机组合          |   平均 CAGR | 抽样标准差 |
| ------------- | --------: | ----: |
| random top200 | **-0.4%** |  1.9% |
| random top100 | **-1.4%** |  2.7% |
| random top30  | **-2.2%** |  5.6% |

随机 topN 是负的（2021 全池等权 +14.3%，但随机组合换手/成本更高，且抽样有波动）。top500 的 +20.3% 与随机 null 相差 **20+ 个点**；这不是小盘 beta，也不是“2021 年随便买都赚钱”。

### 2.4 tilt 对照：Brandt 式线性 tilt 在这批分数上不成立

下面这张表来自快速核算（同一批分数、21 日前向收益、25bp 权重空间成本），**只看相对排序，绝对水平不能和 §2.1 的硬引擎表比**。

把权重写成“等权 + λ × 分数倾斜”，或“等权 + λ × 排名倾斜”，λ 从 0.1 到 1.0：

| 规则                        |   CAGR | Sharpe |  换手 |  持仓 |
| ------------------------- | -----: | -----: | --: | --: |
| tilt_softmax λ=1（快速口径的政策） | +11.8% |  0.632 | 98% | 810 |
| tilt_rank λ=1             | +11.5% |  0.641 | 65% | 853 |
| tilt_softmax λ=0.5        |  +7.9% |  0.438 | 64% | 893 |
| tilt_rank λ=0.5           |  +7.6% |  0.432 | 43% | 893 |
| tilt_softmax λ=0.1        |  +4.8% |  0.273 | 32% | 893 |

**结论**：小 tilt 越轻越接近全池等权；tilt 再重也追不上 top500。原因是这批分数的**底部有负 alpha**（2021 十分档 bottom -1.6%/21d），任何“保留全部 900 只、只做平滑倾斜”的映射都会把底部拖进来。**这里需要的是“截断”，不是“tilt”。** 这一点和 Brandt (2009) 的线性 PPP 不同：Brandt 的基准是市值权重，特征与收益的关系更接近单调；我们的分数是“选股分数”，底部是要被排除的。

### 2.5 分数层本身没有坏

- 测试窗口 rank IC = **+0.0987**，IC-IR 2.74，t=2.74，胜率 83%（score_diagnostics.json）。
- 十分档：top +3.25%/21d，bottom -1.60%/21d，spread **+4.85%/21d**。
- 同一批 70 列输入，逐股 Ridge IC +0.1055，随机森林 +0.1010；政策 +0.0987。**三条独立路径同一个量级，softmax 没有吃掉分数层的信号。**
- 2022 fold 1 的 IC 降到 +0.0764（t=1.56），Ridge/RF 归零/转负；这是信号不稳定，不是映射问题。fold 1 的硬引擎结果见 §2.6——**2021 的映射增益在 2022 没有活下来**。

**怎么读：**

1. 2022 是长-only 的熊市年，所有变体都亏 25%-29%；映射层带来的差异最多 3.5 个点，且在噪声范围内。top500 比全池等权好 0.7 个点，policy 差 0.4 个点，top200 最差 -28.3%。**2021 的 +6 个点映射增益，在 2022 基本归零。**
2. 这不是“softmax 训练失败”，而是**长-only beta 主导**：分数层 IC 0.076（t=1.56）只能提供很弱的截面倾斜；市场跌 25%，任何 900 只 long-only 组合都难逃。
3. 文献里的 AlphaPortfolio 是 **long-short dollar-neutral**，softmax 分别在 top G 和 bottom G 内做；它赚的是两端价差，不是市场 beta。我们的长-only 组合只用了 top 端，且现金节点最多 8%，无法对冲 2022 的 beta。
4. **所以 top500 不是“稳健 alpha”，它是 2021 这个 regime 的映射改进。** 要让它跨年，下一步必须处理 beta/对冲，而不是继续调 softmax 温度。

### 2.7 把 2021/2022 的 P\&L 拆成 beta 和 alpha

用同一台硬引擎跑 **全池等权（ew_all）** 作为基准，把每条规则的日净收益对基准做 OLS：

```
r_p,t = alpha + beta * r_b,t + eps_t
```

alpha 年化 = 日 alpha × 252；t 值用 Newey-West（5 阶）。"对冲后"是 r_p - beta * r_b 的复利结果。基准和策略用同一套成本/执行，所以截距不是费用差。

2. **2022 的亏损基本是 beta。** top500 alpha 仅 **-0.96%（t=-3.21）**，beta 0.934；原始 -24.8% 对基准 -25.5%，对冲后只剩 -1.1%。政策 softmax 的 alpha 是 -1.17%（t=-8.0），也远小于 -25.9% 的原始亏损。**"2022 映射失败"应更正为"2022 是 long-only beta 年，映射层只贡献约 -1 个点的 alpha"。**
3. **但 alpha 的跨年衰减是真的。** 两年拼接后 top500 alpha 只有 **+2.55%/年（t=15.8）**，对冲后 +2.4%、Sharpe 0.46；2021 的 +6.16 在 2022 变成 -0.96。**这不是"没有 alpha"，而是 alpha 不稳定且幅度小；绝对收益被 beta 放大后，看起来像策略失败。**
4. **softmax 全市场分配器没有 alpha。** 政策 softmax 两年 alpha **-0.23%（t=-1.50）**，而它的分数层 IC 是 0.099/0.076。**分数有信息，softmax 读出没有把信息变成 alpha；top500 等权反而有 +2.55%。** 这是 §4.1"作用域错配"的直接证据。
5. **越窄越差。** top100 两年 alpha -2.88%（t=-7.3），top30 -4.98%（t=-12.1）；top100 在 2021 的 alpha 只有 +0.35（t=0.52）。**高分尾部在扣费/波动后不再有 alpha；宽顶部（top300-500）才是这批分数的有效载体。**
6. **下行 beta 不对称。** 2022 top500 的下行 beta 是 **1.000**，高于全样本 beta 0.934；政策 softmax 下行 beta 1.025。**熊市里组合的 beta 不是下降而是上升**，这比"平均 beta=1"更糟；对冲/降 beta 在 2022 是有效的，但空 EW 全池不可实施，需 IF/IC 或 ETF 空头并计基差/保证金。
7. **口径限制：** 基准是"全池等权、同一引擎"，不是沪深 300；"对冲后"是 **synthetic short EW**，没有融券费、期货基差、保证金和冲击成本。它回答"收益里有多少是 beta"，不回答"对冲后能拿到多少净钱"。真实对冲要用 IF/IC 基差和 300/500 ETF 融券成本重算。

scale = max(|w_target|, 1e-9)

5. **实现上修了一个会悄悄废掉 band 的 bug：** 原逻辑把 blended 的现金权重也带进重投影，被跳过的股票权重会漏给 slack 最大的票，导致 band 看似生效、实际没保住目标。现在现金取股票目标的残差，并保留"全退出不受 band 阻挡"。test_execution 15 条、全套 49 条测试通过。

## 3. 文献精读：softmax 在股票数据上到底怎么训练

> 这一节不是摘要复述；下面每一条都来自 PDF 的模型构建/训练章节。引用页码为工作稿页码，便于回查。

### 3.1 AlphaPortfolio（Cong, Tang, Wang & Zhang, NBER WP 35195, 2026；前身 “Direct Construction…”, 2020）

**这是和我们的问题最接近的一篇。** 它同样是“特征 → 分数 → 权重”的直接构建，同样用 softmax，但它在三个地方和我们不同。

**(a) softmax 只作用在短名单，不作用在全市场。**  
模型先对每只股票算一个 desirability score：

```
s_i,t = MLP(c_i,t; theta)
```

然后按分数排序，取 **top G** 和 **bottom G**（G = 全市场股票数的 10%），在每条 leg 内分别做 softmax：

```
w+_i,t = exp(s_i,t) / sum_{j: o_j,t <= G} exp(s_j,t)      if o_i,t <= G
w-_i,t = -exp(-s_i,t) / sum_{j: o_j,t > I_t-G} exp(-s_j,t)  if o_i,t > I_t-G
w_i,t = 0 otherwise
```

（Eq. 9-11，§2.3，pp. 15-16）

不是 900 路 softmax，而是 **“先排序截断，再在 G 只内 softmax”**。G 的选择是 **10%**；以 3000 只股票计，G ≈ 300。**这和我们扫描出来的 top300-top500 宽顶部是同一个数量级。**

**(b) 目标函数是路径级的 Sharpe，不是一期组合收益。**  
训练目标是“后续 12 个月投资窗口的 OOS Sharpe”：

```
J(theta) = E_{tau~P_theta}[H(tau)],  H(tau) = Sharpe({R^p_{t+1}(theta)}_{t=1}^T)
grad_theta H(tau) = sum_t (dH/dR^p_{t+1}) grad_theta R^p_{t+1}(theta)
```

（Eq. 19-20，§2.5，pp. 23-24）

每个 episode 是 **24 个月**：12 个月 lookback + 12 个月 reward window；训练时随机抽起始月，重叠采样；30 个 epoch；学习率 1e-4 → 5e-5 → 1e-5；**1,788,673 个参数，640,722 个 stock-month 观测**；不做单独验证集，靠严格 OOS 和年度 fine-tune（§3.2，pp. 26-27）。  
对比我们：**2818 个参数，70 个决策日，一期 21 天收益，24 个验证决策**。参数/样本比和 reward 的时间跨度都差两三个数量级。

**(c) 它明确解释了为什么用 softmax，而不是市值权重。**  
§3.3（p. 33）：

- softmax 可微，能反传；市值权重与分数没有梯度关系，会阻断训练。
- 同样 top/bottom decile，用市值权重代替 softmax，OOS Sharpe **低于 1.5**；softmax 版 **约 2.0**；换手、最大回撤也更差。  
  这说明 softmax 的价值在于“**在短名单内可微地分配**”，不是“在全市场内做归一化”。

**(d) 结果**：全样本 OOS Sharpe **2.0**；剔除 microcap 后更高；最大回撤 2%-10%；换手低；加 10-100bp 交易成本后仍可比（§3.3、§4.2）。  
**可迁移的三点**：G=10% 的短名单；路径级 Sharpe；softmax 只在 shortlist 内。

### 3.2 EIIE（Jiang, Xu & Liang, 2017, arXiv:1706.10059）

**这是“softmax 组合”的工程原型。**

- 输入：价格张量 X_t ∈ R^{3×m×n}（high/low/close × m 个资产 × n 期），按当前价格归一化。
- 网络：每只资产一个共享参数的 CNN/RNN 子网络（Identical Independent Evaluators），最后每只资产出一个 voting score；**softmax 在 m 个非现金资产 + 一个 cash bias 上做**，输出权重和为 1（§5.1，pp. 12-13）。
- **上一期组合权重 w\_{t-1} 在 voting layer 之前插入网络**，让模型自己学“少交易”（§5.2，pp. 13-14）。这是一个我们完全缺失的输入。
- 目标：episode 平均对数收益

  R = (1/t_f) ln(p_f/p_0) = (1/t_f) sum_t ln(mu_t y_t · w\_{t-1})

（Eq. 21-22，§4.2，p. 11）

- 训练：deterministic policy gradient；**按时间顺序的 mini-batch**；Portfolio-Vector Memory 存上一期权重，使 batch 内可并行；Online Stochastic Batch Learning 用几何分布采样近期 batch（§5.3，pp. 15-16）。
- 实验是 **11 个加密货币、30 分钟周期**，不是股票；但方法结构（cash 节点、prev weights、episode reward）是可迁移的。

**关键限制**：m=11。它没有回答“900 只股票怎么做 softmax”；硬套到 900 只就是我们的现状。

### 3.3 Zhang, Zohren & Roberts (2020, arXiv:2005.13665)

**这是“softmax + 直接 Sharpe”的干净版本。**

- 输入：把 n 个资产的价格/收益拼成一个 (k, 2n) 的矩阵；k=50 天。
- 网络：单层 LSTM，64 units；输出层 **softmax over n assets**，long-only、和为 1（Eq. 4-5，§3.1-3.2，pp. 3-4）。
- 目标：直接最大化 Sharpe

  L_T = E(R_p) / sqrt(E(R_p^2) - E(R_p)^2)  
  R_p,t = sum_i w\_{i,t-1} r\_{i,t}

（Eq. 1-3）

- 训练：Adam，batch 64，100 epochs，10% 验证；每 2 年重训；加波动率缩放和交易成本（§4.3，pp. 5-6）。
- 实验是 **4 个 ETF**（VTI/AGG/DBC/VIX），不是 900 只股票。

**关键限制**：n=4。它证明了“softmax 输出层 + Sharpe 目标”可训练，但没有回答大规模截面。

### 3.4 ListNet / Learning-to-Rank（Poh, Lim, Zohren & Roberts, 2021, arXiv:2105.10019）

**这是“softmax 作为逐股损失”的最直接参考。**

- 场景：31 个货币的横截面动量；先由 base ranker 选 top/bottom m=10，再用 Transformer encoder（带 positional encoding）re-rank；最后多 top 3 / 空 bottom 3，等权（§4-5，pp. 3-5）。
- 两个损失：
  - Pairwise logistic：l = sum_i sum_j 1(y_i>y_j) log(1 + exp(f_j - f_i))
  - **ListNet**：l = -sum_i softmax(y)\_i log softmax(f(x))\_i
  （Eq. 13-14，§5.3，pp. 8-9）
- 标签 y 是**下一期收益排序后的 decile labels**；softmax(y) 是真实的相关性分布，softmax(f(x)) 是模型分布，交叉熵让每只股票拿到直接梯度。
- 训练/评估：日频，2000-2020；NDCG@3 和 Sharpe 等（§5.4）。

**为什么这篇重要**：它把 softmax 用在**损失**上，而不是只用在**输出层**上。每只股票都有一个标签，梯度不再被组合权重 0.1% 缩放。我们的分数层 IC 已经和 Ridge/RF 持平，说明“分数能学”；但如果要让 **top100 的尾部**也可靠，ListNet 这种逐股 listwise 损失是下一步最该加的。

### 3.5 Brandt, Santa-Clara & Valkanov (2009, RFS)

**这是“直接权重函数”的祖师爷，也是 tilt 对照的来源。**

- 权重函数：

  w_i,t = w_bar_i,t + (1/N_t) theta' x_hat_i,t

  x_hat 是截面标准化后的特征；w_bar 是基准（如市值权重）；1/N_t 让权重函数可随股票数变化；权重和为 1（Eq. 3，§2.1，pp. 4-5）。
- 目标：最大化组合收益的期望效用（CRRA），对 theta 做无约束优化；可加 long-only、交易成本、no-trade boundary。
- 实证：CRSP 1974-2002，3 个特征（市值、BM、12 个月动量），CRRA=5；样本外 certainty equivalent gain 5.4%（相对市值组合）；no-trade boundary 可把换手降 50%（§3）。
- **它不是 softmax**；它是“基准 + 线性 tilt”。我们这次用同样的 tilt 形式测了，结果不如截断（§2.4）。原因是我们的分数底部有负 alpha，而 Brandt 的基准/特征关系更接近单调。

### 3.6 对照：GKX (2020, RFS)、Chen-Pelger-Zhu (2024, Management Science)、Kelly-Malamud-Zhou (2024, JF)

这三篇不是 softmax 组合，但它们解释了“为什么我们的有效样本量这么小”。

- **GKX**：94 个特征、约 30,000 个 stock-month；NN1-NN5 的隐藏层是 32/16/8/4/2；Huber 损失 + l1 + early stopping + batch norm + ensemble；多空 decile Sharpe 1.35。**每只股票一个标签**，不是每期一个组合收益。
- **Chen-Pelger-Zhu**：46 个 firm characteristics + 宏观状态；FFN 两层、4 个经济状态、8 个工具；矩条件/GAN 目标；**9 个模型 ensemble**；OOS Sharpe 2.6。
- **Kelly-Malamud-Zhou**：P > T 的 random-feature/ridge 在小样本下也可能优于简单模型，但需要正确的 shrinkage；他们研究的是市场时序，不是 900 只股票的截面 softmax。**“参数多”本身不是死刑，但“每期只有一个标量监督”是。**

**共同点**：顶刊里的股票 ML，监督粒度几乎都是**逐股/逐股-月**，而不是“每期一个组合收益”。我们的 70 个决策日 × 1 个标量，是异类。

## 4. 对照我们的方法：三个错配

### 4.1 softmax 的“作用域”错配

文献里的 softmax 几乎都是**短名单内的分配器**：AlphaPortfolio 的 G=10%，EIIE 的 11 个资产，Zhang 的 4 个 ETF。我们的 softmax 是**全市场选择器**：900 路竞争，3% 上限再把权重压平。结果就是 §2 的 +15.1%——比全池等权只多 0.8 个点。  
**这不是 softmax 的错，是“让 softmax 做它不擅长的事”。**


### 4.2 监督粒度错配

文献里的股票 ML 几乎都是逐股监督（GKX、Chen、ListNet）；我们的监督是每期一个组合收益。softmax 输出层本身可训练，但**信用分配**被 0.1% 的权重缩放。  
**证据**：分数层 IC 0.099 与 Ridge/RF 持平——说明“分数能学”；但 top100 的种子间 CAGR 6.7%-24.4%——说明“尾部不稳”。逐股 listwise 损失是让尾部稳下来的直接办法。

### 4.3 状态/换手错配

EIIE 把 w\_{t-1} 喂进网络；我们的 build_state 永远传 0。模型看不到自己持有什么，只能每期从零算权重，换手自然高（政策 1426%，top500 1329%，top100 2313%）。  
**这不是“加个 no-trade band”就能完全解决的**：band 是事后补丁；prev weights 是让模型自己学“不该交易”。

## 5. 改进方案（按优先级）

### P0：不改模型，只改读出（今天就能做）

1. **把读出改成 top500 等权（或 top300 等权）+ 3% cap**。
   - top500：+20.3% / Sharpe 1.16 / maxDD -9.0% / 换手 1329% / 成本 261bp。
   - top300：+20.7% / Sharpe 1.155 / maxDD -11.5% / 换手 1781% / 成本 338bp。
   - 这是同一批分数，**不需要重训**；比政策网络多 5.2 个点。
2. **把 no-trade band 改成“相对于目标权重”**，不是相对于 NAV。
   - 上一轮的 25bp × 10M = 25,000 元，而 900 只票每只 11,000 元，阈值大于仓位，组合被冻结；这是参数错误，不是 band 无用。
   - 建议：|w_target - w_current| / max(w_target, 1e-4) < 20%-30% 才跳过交易；先用引擎扫 10%/20%/30% 三档。
3. **不要用 softmax 在 top100 内加权**。
   - 等权 top100 +11.8% > softmax top100 +8.9%；短名单内等权更稳。
   - 如果一定要加权，用 zpos 或 pow 的温和版本，不要 T=0.03 的尖 softmax。
4. **现金节点先关掉/加无风险收益**。
   - 股票 only softmax +17.8% vs 含现金 +15.1%；2021 年现金 0 收益是拖累。
   - 至少给现金一个真实的短端利率，或者在验证集上给现金权重加惩罚。

### P0.5：beta 分解已完成（2026-10-19）

用同一台硬引擎的全池等权（ew_all）做基准，日净收益 OLS + Newey-West(5)：

| ---------- | ------------------: | --------: | ------------------: | --------: | ------------------: | ------: |

读法：

1. **2021 的映射增益是显著 alpha，不只是 beta。** top500 对冲后仍有 +6.2%、Sharpe 1.21；此前"2021 只是 regime"的怀疑被否掉一半。
2. **2022 的亏损基本是 beta。** top500 alpha 仅 -0.96%，原始 -24.8% 对基准 -25.5%，对冲后 -1.1%。政策 softmax alpha -1.17%。**"2022 映射失败"应更正为"2022 是 long-only beta 年，映射层只贡献约 -1 个点 alpha"。**
3. **但 alpha 跨年衰减到 +2.55%。** 2021 的 +6.16 在 2022 变成 -0.96；绝对收益被 beta 放大后，看起来像策略失败。
4. **softmax 全市场读出没有 alpha。** 政策 softmax 两年 alpha -0.23%（t=-1.5），而分数层 IC 是 0.099/0.076。**分数有信息，softmax 分配没把信息变成 alpha；top500 等权反而有 +2.55%。**
5. **越窄越差。** top100 两年 alpha -2.88%，top30 -4.98%；top100 在 2021 只有 +0.35（t=0.5）。宽顶部（top300-500）才是这批分数的有效载体。
6. **下行 beta 不对称。** 2022 top500 下行 beta 1.000，高于全样本 0.934；政策 1.025。熊市里 beta 不降反升；对冲/降 beta 有效，但空 EW 全池不可实施，真实对冲要用 IF/IC 或 ETF 空头并计基差/融券。

**因此评估口径改为：绝对收益 + 相对 ew_all 的 alpha + beta 三者并列。** 不再把 2022 的 -25% 当成选股失败；也不把 2021 的 +20% 当成可复制的跨年 alpha。

#### P1.1 ListNet v2：两个权重都失败

4. **机制判断**：ListNet 在未截断的 scores 上做逐股 softmax 交叉熵，组合损失在截断后的权重上做一期增长；两个梯度在 2,818 参数的小网络上互相拉扯。弱权重下排序仍被破坏，说明问题不是"辅助损失太强"，而是**这个 ListNet 形式与组合目标不兼容**；继续扫 alpha 没有依据。

#### P1.2 chronological 训练：成本路径把模型推向"全持有"

把训练样本按日期顺序走、每期把上一期的 held 传入成本项，并逐 batch 传递 prev_cash/prev_hold：

| 配置             |    选中 epoch |          valid IR |         测试 score IC | dense CAGR / Sharpe / maxDD |          换手 / 成本 |      持仓 |
| -------------- | ----------: | ----------------: | ------------------: | --------------------------: | ---------------: | ------: |
| p1 基线（shuffle） |       26-37 |         1.05-1.21 |          **0.0987** |               +17.9% / 0.95 |    1426% / 264bp |     875 |
| chronological  | **11/11/9** | 0.905/0.853/0.826 | **0.0815** (t=1.57) |  **+13.4% / 0.876 / -8.0%** | **807% / 165bp** | **927** |

1. **验证集把最优停在了第 10 轮附近**：此时温度还高，softmax 接近全市场等权，换手和成本最低；真实成本路径下"全持有 + 少动"确实是验证集的最优解。
2. **成本降了 99bp、换手降了 619 个百分点，但收益掉了 4.5 个点**；score IC 也从 0.0987 掉到 0.0815。**省成本不等于赚钱，模型在早期就停止了分化。**

1. **A 证明选型指标不是根因。** 改成正的验证期 rank IC 后，三个 seed 仍选在 epoch 10–12，valid IC 为 0.111/0.091/0.090；test IC 只从 0.0815 升到 0.0827，top500 仍只有 +13.8%。后段 breadth 掉到 90–130，是模型自己在集中，不是选型把它提前停住。
2. **B 证明温度退火也不是唯一原因。** 固定 T=0.6 后，epoch 20 的 breadth 仍是 72/104/108（seed 0 的 cash 已到 0.336），说明不降温也会集中。B 的 dense 是 v3 最好（+14.9% / Sharpe 1.117），但 top500 反而最差（+12.7%），dense 的改善没有映射到可部署的 500 只。
3. **C 把 score 选型换回来，top500 恢复到 +16.1% / Sharpe 1.163**，是 v3 最好的可部署结果，但仍比 p1 少 4.2 个点。B/C 的 test IC 几乎相同（0.0845 vs 0.0851），收益差异来自选中的 epoch 与集成（C 的 seed 2 选中 epoch 1，几乎是等权模型），不是分数排序本身。
4. **D 把“训练顺序”单独拆开，结果也不是顺序本身。** shuffle + 固定 T=0.6 + score 只有 test IC **0.0700**、top500 **+15.4% / 0.834**、换手 1787% / 成本 321bp；比 C 更差。seed 0 在验证集选中 epoch 23 的 40 只、26% 现金组合（valid score 0.232，test IC +0.0224），说明 score 选型在 shuffle 下也会被“幸运的集中组合”骗。**p1 的 +20.3% 不是“shuffle”单独带来的，而是 shuffle + 退火到 0.1 + score 选型的组合；固定温度把退火拿掉后，shuffle 也不成立。**
5. **剩余 4 点不是单个开关，而是退火 + 选型 + 训练路径的交互。** chronological 每 epoch 只有 5 个连续 16 日 batch（约 336 天/批），batch 间高度相关；p1 的 shuffle 每 batch 是随机日期，梯度更多样，而且上一期持仓在随机日期间传递。这个“随机 batch 提供正则”的假设与 D 一致（单独换 shuffle 不够），但还没有单独验证。
6. **F 证明“晚轮模型其实更好、只是被早停”不成立。** chrono + 原退火 + 强制第 24 轮（`--selection last --epochs 24`）三个 seed 的 breadth 只有 **5 / 4 / 9 只**，test IC **0.0536**（t=1.57），dense **+14.7% / 0.830 / -9.9%**，top500 **+12.7% / 0.743 / -10.2%**（换手 1657%、成本 299bp）。晚轮模型已经塌缩成个位数持仓，早停是在保护组合，不是过早停掉好模型。
7. **E 证明成本目标也不是根因。** 把训练/验证成本从 25bp 降到 0 后，test IC 反而从 C 的 0.0851 降到 **0.0728**；dense 升到 +16.0% / 1.040，但 top500 只有 **+15.8% / 1.129**，仍低于 p1 的 +20.3%，换手还从 1269% 升到 1584%、成本从 244bp 升到 291bp。去掉成本项只是让模型更愿意换手，没有恢复 alpha。
8. **到 E 为止，选型、固定温度、强制晚轮、训练顺序、成本目标五个开关都试完，没有任何一个能把 chrono 的 top500 拉回 p1 的 +20.3%。** 固定温度/IC 选型最多补回约 2 个点且方向不一致；继续扫 G、温度或 alpha 没有依据。p1 的 shuffle + 退火 1.0→0.1 + score 是 2021 上唯一可复现的 +20% 配方，但它依赖随机 batch 与退火的交互，不能简单搬到 chronological。

#### P1.7 最终 quasi-holdout：同一 p1 配方，2023-2026 六种读出相对市值加权基准都没有正 alpha

**设计（预注册，测试期不调参）**

- 训练 2013-01-01..2020-12-31（93 个决策），验证 2021-01-01..2022-12-31（24 个），测试 2023-01-03..2026-09-28（42 个决策 / 906 个交易日）。2021/2022 只用于早停，不进入训练。
- 固定 p1 配方：70→32→16→1、dropout .1、L2 1e-3、dense softmax+cash、温度 1.0→0.1、score 选型、shuffle、40 epochs/patience 12、25bp 训练成本、3% cap、seeds 0/1/2。**没有为测试期改任何超参。**
- 读出六种：policy_softmax_all（模型自己的权重）；ew_top500（等权前 500）；ew_top10pct（等权 top decile）；vw_top10pct（同一 decile 内市值加权）；ew_all（全部 eligible 等权，1/N）；vw_all（全部 eligible 市值加权）。硬引擎 25bp 左右、partial 1.0、band 0、3% cap、21 日调仓；测试期从现金开始。
- **不是干净 OOS**：`qlp/splits.py:19` 定义 `CONTAMINATED_FROM=2023`，2023+ 的因子层/参数选择在更早的研究中已经看过；模型没有见过 2023-2026 的标签，但因子定义不是 pristine。所有结论只能称 quasi-holdout，不能称无偏 OOS。
- **选型本身也不稳定**：三个 seed 的 best epoch 是 13/19/36，验证期 breadth 298/29/83，cash 0.2%/4.9%/0；`score = ann_return - 0.5*ann_vol` 把 seed1/2 选到 2021-2022 高收益高波动的集中组合（29/83 只），不是稳定排序模型。

**分数层：+0.037，不是零，但比 2021 弱很多**

- 修正 IC 网格错位后，ensemble test score IC **+0.0369**（n=42）；分年 2023 **+0.0714**、2024 **+0.0811**、2025 **-0.0622**、2026 **+0.0779**（7 个决策）。

## 6. 下一步实验（按顺序）

1. **beta 分解（已完成）**：2021 top500 alpha +6.16%（t=18.1），2022 alpha -0.96%（t=-3.2），两年 +2.55%（t=15.8）；政策 softmax 两年 alpha -0.23%。**2022 不是映射失败，是 long-only beta 年。**
2. **top500 + 相对 band（已完成）**：band 0.5 两折都降成本 70-80bp、降换手 25-30%，净收益不变差；但 beta 从 0.93 降到 0.89，2022 的改善主要来自低 beta。**band 0.5 仍是工程上值得保留的选项，但它救不了 alpha。**
3. **ListNet v2（已完成，失败）**：alpha=0.01 与 0.001 都伤 score IC 和组合；top500 分别 +8.3%/+16.5%，低于基线 +20.3%；alpha=0.01 的 top500 alpha 为 -6.6%（t=-9.5）。**当前 ListNet 形式与组合目标不兼容，停止扫 alpha。**
4. **top-G softmax v2 与后续读出修复（全部失败）**：G=500 训练时截断后 top500 +14.1%/Sharpe 0.883，几乎等于全池等权 +14.3%。随后按顺序试了验证期 rank IC 选 epoch（A）、固定 T=0.6（B/C）、强制第 24 轮（F）、训练成本 0（E）；最好的可部署结果是 C 的 **+16.1%/1.163**，仍比 p1 的 +20.3% 少 4.2 点。**"训练/推理映射一致"、选型、温度、早停、成本目标都不是根因；停止扫 G=100/300 与温度。**
5. **prev weights v2（按用户要求停止，未产出结果）**：71 列输入、chronological 下逐期传 prev_cash/prev_hold/prev_weight 的代码已就绪，训练/回测路径已对齐；实验启动后被要求停止，**没有可报告的收益/换手数字**。恢复后与同一 chronological 基线对照 dense/top500，**不与 shuffle 基线混比**。
6. **最终 quasi-holdout（已完成，负结果）**：同一 p1 配方，train 2013-2020 / valid 2021-2022 / test 2023-2026；六种读出（policy softmax、ew top500、ew top decile、vw top decile、ew_all、vw_all）全部跑不过 **vw_all 的 +7.41% / Sharpe .475 / maxDD -18.56%**；策略相对 vw_all 的 alpha 全是负点估计（-3.76% 到 -12.21%/yr），t 值 -0.48 到 -1.50。**p1 的 +20.3% 是 2021 regime-specific，不是可部署策略。**
7. **P2 因子（只在监督重做后）**：COMMOVE/INTRADAY/OVERNIGHT/LEAD_LAG/TURN_SHOCK 先测单因子 rank IC；行业/市值中性化；microcap 剔除。**在 score 层没有独立验证之前，不要再把这些因子倒进端到端 softmax。**
8. **决策门**：不再扫 softmax 的 alpha/G/温度/band；若继续，先做**逐股 21 日标签 + purged/embargo CV** 的 score 模型，用固定 decile 读出和 cap-weighted 基准验证，再谈组合层。否则这条线应停在“研究结论”，不进生产。

## 7. 一句话给决策

**2021 的映射 alpha 是真的（+6.16%，t=18.1），2022 的亏损是 beta；但 2023-2026 的最终 quasi-holdout 把“可部署”否掉了：六种读出没有一个跑赢被动市值加权全池，p1 的 +20.3% 不能外推。**

- 2021：top500 等权 + 3% cap 把政策网络的 +15.1% 拉到 +20.3%，对冲后仍有 +6.2%、Sharpe 1.21；随机对照 -0.4% 到 -2.2%。**这一年映射层确实抓到了截面 alpha。**
- 2022：top500 -24.8% vs 全池等权 -25.5%，但对冲后只有 -1.1%；**这不是选股失败，是 long-only beta。** 下行 beta 1.000，熊市里 beta 不降反升。
- 2023-2026（quasi-holdout）：policy softmax **-0.12% / -0.005 / -32.87%**，top500 **+2.08% / .087 / -35.65%**，等权 top decile **-4.11%**，而 **vw_all +7.41% / .475 / -18.56%**。策略相对 vw_all 的 alpha 全为负点估计；**分数没有变成可交易的 alpha。**
- 分数层不是完全没信息：test IC **+0.0369**，long-short top-bottom **+1.24%/21d**（年化 +14.9%，naive t .85）；但 2025 IC **-0.062**，long-only top decile 在 2023/2025 都亏钱，2024 又错过市值加权大盘年（vw_all +17.5% vs policy +1.0%）。**有方向、没强度、没稳定性。**
- **softmax 不是根因，但也不是救世主。** 政策 softmax 两年 alpha -0.23%；2021 post-hoc softmax +15.6% 输给等权 +20.8%；最终 holdout 的 policy softmax 又是六种读出里最差。文献里的成功案例靠逐股标签 + 月频 decile 组合，不靠 900 只一路 softmax 加一个组合收益。
- **p1 不再是生产候选，只是 2021 研究基线。** C 的 chrono + 固定 T=0.6 + score 也只有 2021 证据；不要因为 +16.1% 就上线。当前唯一可辩护的结论是：**这条“端到端组合收益 + 月频 long-only + 高换手”的路线在 2023-2026 没有 alpha。**
- 若还要继续，下一件事不是调参，而是重做监督/验证：逐股 21 日标签、purged/embargo、扩大独立验证、固定 decile 读出、cap-weighted 基准、long-short/hedged 纸上组合；先证明 score 在 2023+ 有稳定 IC，再谈 softmax。**否则应停止，把这次负结果当作结论。**
- 短名单 long-only 仍是 beta 产品，除非加空头/对冲；评估固定为"绝对 + alpha + beta"三列。
