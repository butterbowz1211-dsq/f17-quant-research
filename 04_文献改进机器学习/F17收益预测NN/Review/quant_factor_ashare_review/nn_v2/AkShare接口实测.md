# AkShare 能否补齐缺口：2026-10-20 实测

**可以补一部分，已拿到真实返回；目前不能一次性补齐严格历史回测所需的全部数据。**

在独立 `.akshare-env` 中安装并实测 AkShare **1.19.1**。共 13 个初始用例，其中 6 个传输失败用例做了有上限的重试；证书验证始终开启。没有购买数据，没有使用用户凭据，没有批量请求全部股票。原始结果与错误均留存。

| 需求 / 接口 | 实际返回 | 对本项目的意义 |
|---|---|---|
| `stock_dividend_cninfo("600000")` | 26 条，公告覆盖 2000—2026；有登记/除权/派息/到账字段 | 能作为公司行动的一个来源，但部分日期/比例缺失 |
| 同接口 `"600005"` | KeyError；公司概况接口返回空 | 当前/历史退市证券覆盖不一致，不能只保留取得数据的存续股 |
| `stock_history_dividend_detail(...,"分红")` | 600000 为26条，600005 为18条 | 新浪可补巨潮漏掉的历史证券；无统一完整派息到账信息 |
| `stock_info_sh_delist("全部")` | 161 行 | 用于证券覆盖核查；存在6个公司代码重复键，上市日期不同 |
| `stock_info_sz_delist("终止上市公司")` | 209 行 | 提供上市/终止日期；不等于退市现金结算 |
| `stock_info_sz_change_name("简称变更")` | 7,495 行，1994—2026 | 提取1,630条 ST 状态变更候选；逐股简称链未发现相邻断裂 |
| `stock_zh_a_st_em()` | 404 行当前快照 | 不能回填为2013—2026日级 ST历史 |
| `stock_tfp_em("20260928")` | 36行，其中22行停牌开始日晚于请求日 | 日期契约不满足历史快照用途 |
| `stock_tfp_em("20130603")` | 4,175行，开始日期2013-06-06至2026-10-19 | 全部晚于请求日，不能用来判断2013-06-03当日状态 |
| `stock_zh_a_daily("sh600000", adjust="qfq-factor")` | 29条调整因子 | 值得与原始价格交叉验证；不能从乘法因子推断分红现金/送转到账 |
| 同日线接口请求 `"sh600005"` | 重试后 JSONDecodeError | 未取到该证券的新浪历史日线；已有 Tushare 原始历史已保留 |

交易所名单与原面板遗漏的 270 个沪深代码匹配：**266 个命中终止上市目录，4 个未匹配**（sh689009、sz000022、sz000043、sz300114）。目录包含合并等情况，不能把“终止上市”统一解释为破产归零。上交所接口返回公司代码而非完整证券标识时，同一公司可能出现不同上市日期；已保留原记录并标注歧义，没有选择有利的一条。

深市简称变更可为日级 ST 重建提供有效日事件，但尚未完成全部证券初始状态、沪市对应事件、公告可得时间及停牌/涨跌停联动的交叉核验。没有把它升级成全市场历史 ST 已完成。

## 已落盘

- `akshare_probe/`：首轮原始 CSV、字段、日期范围、空值率及错误。
- `akshare_probe_retry1/`：保留 TLS 校验的有界重试。
- `akshare_assessment/missing_security_resolution.csv`：270个代码逐项核对。
- `akshare_assessment/sz_st_transition_candidates.csv`：深市 ST 生效事件候选。
- `akshare_assessment/corporate_action_candidates.csv`：每10股转换到每股的分红/送转候选，`verified=False`，未知净股息保留缺失。
- `akshare_assessment/assessment.json`：机器可读结论。

## 尚不能通过的部分

还缺完整历史证券的公司行动与到账核验、税后现金假设、并购换股和退市结算、沪市日级ST、可用开盘交易状态/限价、历史股本与行业来源。部分原 F17 输入的缺失不能由分红表补齐。AkShare 成功返回一个样本不等于全历史全股票覆盖完成。

后续可优先扩展分红双来源交叉核验和深市名称事件，但应逐批记录覆盖率，不把当前名单回溯成历史名单。本次仍按用户已确认的范围交付代码与缺口清单，未开始正式51次拟合。

接口说明参见 [AkShare 股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)。文档用于定位接口；以上数量、成功/失败和日期异常均来自本地实际请求，未用文档示例代替实测。
