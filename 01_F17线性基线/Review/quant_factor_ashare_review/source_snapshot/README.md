# 中国 A 股截面因子量化策略

在全 A 股横截面上，用一组有学术文献支撑的**截面联动类因子**给股票打分，  
买入排名靠前的组合，并用多种统计方法检验其显著性。

---

## 目录结构

```
quant_factor_ashare/
├── ashare_factor_strategy.py   ★ 主交付物：单文件全流程（10 个分段，逐段注释）
├── build_panel.py              数据面板构建（长表，供策略加载）
├── fetch_sina_stock.py         逐股前复权行情 + 流通股本 + 换手率（多进程）
├── fetch_tushare_daily.py      全市场原始行情（按交易日循环，消除幸存者偏差）
├── fetch_baostock_st.py        时点 ST 标记 + 行业分类（月末快照）
├── probe_*.py                  数据源可行性探测脚本（保留备查）
├── data/                       数据缓存（抓取产物，可删除后重建）
└── output/                     回测报告、图表、JSON 结果
```

## 快速开始

```powershell
# 1. 抓数据（三步可并行，互不依赖）
python fetch_sina_stock.py --workers 7      # ~45 分钟，5367 只
python fetch_tushare_daily.py               # ~90 分钟，4065 个交易日
python fetch_baostock_st.py                 # ~35 分钟，201 个月末快照

# 2. 构建面板
python build_panel.py

# 3. 全流程回测
python ashare_factor_strategy.py --stage all        # LSY 股票池（主口径）
python ashare_factor_strategy.py --stage all --lsy 0  # 全 A 对照（稳健性）
```

`--stage` 可选 `factors`（只算因子）/ `test`（只做单因子检验）/ `backtest` / `all`。

## 一、为什么数据源要这么绕

实测本机环境下各数据源的可用性：

| 数据源                   | 状态         | 说明                                  |
| --------------------- | ---------- | ----------------------------------- |
| Tushare `daily`       | ✅ 50 次/分钟  | 按日期取全市场，**天然无幸存者偏差**                |
| Tushare `adj_factor`  | ❌ 1 次/小时   | 不可用                                 |
| Tushare `daily_basic` | ❌ 1 次/小时   | 市值/估值/换手率不可用                        |
| Tushare 财务/资金流/指数成分   | ❌ 无权限      | —                                   |
| AKShare 东财通道          | ❌ IP 级限流封禁 | `stock_zh_a_hist` / `push2his` 全部被拒 |
| **AKShare 新浪通道**      | ✅ 单只 0.9 秒 | 一次调用返回 qfq 行情 + **流通股本** + **换手率**  |
| **baostock**          | ✅ 但 20 秒/只 | 单连接不可并发，仅用于月末快照（`isST` 时点标记、行业分类）   |

**关键约束**：Tushare 拿不到流通股本和换手率（规模因子、换手率因子的地基），  
东财通道被封禁，baostock 太慢不能做主力。因此主力是**新浪逐股通道**。

### 为什么要多进程而不是多线程

akshare 的新浪接口内部用 `py_mini_racer`（V8 JS 引擎）解密返回数据。  
**V8 的分区分配器每进程只能初始化一次**，多线程并发初始化会直接让解释器崩溃：

```
[FATAL:partition_address_space.cc(243)] Check failed: !IsConfigurablePoolInitialized()
```

因此 `fetch_sina_stock.py` 用 `multiprocessing`，每个子进程持有独立的 V8 实例。

### 原始成交价从哪来（规模因子的地基）

流通市值必须用**真实成交价**乘流通股本。但新浪给的是前复权价，被归一化到最新价，  
历史行直接乘股本是错的（茅台 2015 年的 qfq 价只有真实价的几分之一）。

三个来源，优先级从高到低：

1. **Tushare 原始行情 close** —— 精确（最终覆盖率 **100.00%**）
2. **成交均价 VWAP = amount ÷ volume** —— 逐行精确，无需额外请求（最终仅剩 28 行回退）
3. ~~用全历史复权因子中位数回填~~ —— 会把 2010 年的因子套到 2026 年，误差 30-50%，**已废弃**

两个来源都拿到时会做一致性校验。实测结果：

> **Tushare 收盘 vs 新浪 VWAP 相对偏差：中位数 0.587%，95 分位 2.58%，超 5% 仅 0.67%**

这既验证了 VWAP 回退方案可靠，也顺带做了数据质量筛查 —— 这是双通道抓取最大的附加价值。

## 二、防作弊设计

这四点做不到，回测数字就没有意义。

| # | 设计                                  | 实现位置                     |
| - | ----------------------------------- | ------------------------ |
| 1 | **无未来函数**：t 日收盘算因子 → t+1 日**开盘**成交  | SECTION 8 回测引擎           |
| 2 | **无幸存者偏差**：按交易日循环取数，天然包含后来退市的股票     | `fetch_tushare_daily.py` |
| 3 | **可交易性过滤**：停牌 / 涨跌停 / ST / 次新股 一律剔除 | SECTION 2 股票池            |
| 4 | **真实成本**：佣金 + 印花税（卖出单边）+ 滑点，按换手逐日计提 | SECTION 8                |

### 样本内 / 样本外的严格切分

这是防过拟合最关键的一步：

- **因子选择窗口（样本内）**：2010-01-01 ~ 2022-12-31 —— 只用这段决定"用哪些因子"
- **业绩报告窗口（样本外）**：2023-01-01 ~ 2026-09-28 —— 挑因子时**完全没看过**

如果两段重叠，"样本外显著"就是自欺欺人。

### A 股制度校正

> Liu, Stambaugh & Yuan (2019, *JFE*) "Size and value in China"：  
> A 股**最小 30% 市值股票含"壳价值"污染**，是噪音而非定价，必须剔除。

这条如果忽略，多空组合的"超额收益"大半来自买不到的微盘壳股。  
代码同时提供 `--lsy 0`（保留全 A）作稳健性对照。

## 四、因子预处理

1. **MAD 去极值**：中位数 ± 3×1.4826×MAD 截断（比 3σ 稳健，A 股厚尾下 σ 本身会被污染）
2. **行业 + 市值中性化**：逐日横截面回归取残差

   `factor_i = a + Σ b_k·Industry_k + c·ln(流通市值) + e_i`

   剔除"因子只是行业的代理"或"因子只是小市值的代理"这类伪显著。  
   **实现用 Frisch-Waugh-Lovell 定理**把多元回归拆成两步一元残差化，  
   每天计算量从 O(n·k²)（约 3000 万次浮点运算）降到 O(n)，全 A 面板上从 40 分钟降到几秒。  
   已用直接回归数值验证等价（最大差异 1.6e-13）。
3. **横截面 z-score 标准化**
4. **股票池掩码**（非可交易股票不参与排序）

## 五、检验与显著性

### 单因子

- **RankIC**（Spearman 秩相关）：均值、IR、**Newey-West t 值**、IC 胜率
- **十分层回测**：各层前瞻收益、多空组合、**分层单调性**
- **Fama-MacBeth (1973)** 两步截面回归
- 因子换手率

### 组合层面

- **Newey-West t 值**：修正收益自相关，|t|>1.96 为 5% 水平显著
- **定态块自助法**（Politis & Romano 1994）：保留时序依赖的夏普 95% 置信区间
- **PSR**（Bailey & López de Prado 2012）：修正偏度与厚尾的"夏普>0"概率
- **Deflated Sharpe Ratio**（Bailey & López de Prado 2014, JPM）：  
  把"试了 N 个因子再挑最好"的选择偏差折进门槛
- **Benjamini-Hochberg FDR**：因子层面多重检验校正

> **DSR 的一个常见误用**：`Var(SR_trials)` 必须用**实际试过的策略夏普的横截面方差**。  
> 随手设成 1.0 会得到 SR0≈2 的荒谬门槛把所有策略毙掉；设成 0 等于不做校正。  
> 本实现由 24 个因子的多空夏普实际方差算出。

### 稳健性

- **回测引擎自检**：逐日漂移主引擎 vs 向量化近似，日收益相关性应 >0.99
- **交易成本敏感性**：1× / 2× / 3× 成本
- **组合暴露诊断**：综合得分与 SIZE 的截面相关性、持仓平均市值分位
- **子区间**：近 24 / 12 / 6 个月（时效性）

## 六、统计功效的现实约束

在 `t ≈ 夏普 × √年数` 的关系下：

| 样本长度           | 5% 水平显著所需的年化夏普 |
| -------------- | -------------- |
| 3.6 年（2023 至今） | **> 1.03**     |
| 8 年            | > 0.69         |
| 16 年           | > 0.49         |

**短样本区间做量化验证的根本困难不是策略不行，而是样本不够长。**  
因此本报告同时给出样本外（干净但功效弱）与全样本（功效强但选择偏差重叠）两套数字，  
并明确标注各自的可信度。

## 七、已知局限

1. **样本外区间偏短**：2023 年至今约 3.7 年，统计功效有限
2. **涨跌停卖出限制未建模**：调仓日个股跌停时实际无法卖出，引擎按可成交处理，会略微高估
3. **停牌处理**：停牌期间价格前向填充、收益记 0，复牌后按新价计算
4. **融券成本未计入多空组合**：A 股融券难且贵，多空组合用于因子显著性检验，**不代表可复制业绩**
5. **残余幸存者偏差**：新浪通道缺失部分早年退市股（约 150 只抓取失败），  
   已通过 Tushare 按日面板量化缺口，但无法完全消除
6. **行业分类是当前快照**：baostock 只提供最新行业归属，历史行业变更未追溯
