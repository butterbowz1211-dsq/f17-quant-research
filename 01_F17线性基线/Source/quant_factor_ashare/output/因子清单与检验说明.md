## 二、因子是怎么挑出来的（筛选规则）

```
第 1 步  只用样本内（2010-2022）的单因子检验结果
         门槛：|Newey-West IC t| > 2.0  且  |RankIC 均值| > 0.005
         → 24 个候选中通过 18 个

第 2 步  相关性去重：逐个加入，若与已入选因子的平均截面相关 |corr| > 0.7 则丢弃
         → 18 个中再淘汰 1 个，最终 17 个
```

**筛选规则的一个重要设计**：第 1 步明确禁止使用样本外数据。因子选择与业绩验证在时间上完全分离，否则 2023 年之后的业绩就是样本内拟合的结果。

### ⚠️ 被淘汰的那一个因子：REV_1M（已实测确认）

`REV_1M`（月度反转，Lehmann 1990）样本内 RankIC 0.0497、t=15.81，在 24 个因子里排第 6 位，**本应入选**。它被第 2 步淘汰，因为与 `INTRADAY` 的平均截面相关达 **+0.8395**。实测相关矩阵：

| 已入选因子        | 与 REV_1M 的平均截面相关        |
| ------------ | ----------------------- |
| **INTRADAY** | **+0.8395** ← 超过 0.7 阈值 |
| MAX5         | +0.6342                 |
| REV_1W       | +0.4454                 |
| TURN_SHOCK   | +0.4378                 |
| TURN         | +0.2532                 |
| ILLIQ        | −0.0239                 |

而 `REV_1W`（周度反转）与 `INTRADAY` 的相关只有 **+0.3785**，所以它留下了。  
**结论：在 A 股，"月度反转"与"日内反转"是同一个现象的两种表达（>0.84），但"周度反转"是可分离的独立因子。** 这条相关性结构本身就是一个有价值的发现。

### ⚠️ 筛选规则的一个已知弱点（必须指出）

第 1 步的门槛 `|IC t| > 2` 是**对符号不敏感的**——一个因子的排序与未来收益方向相反，只要足够稳定也能入选，然后以"反向信号"的身份进入合成。

这导致三个因子的入选理由并不干净：

| 因子        | 样本内 RankIC            | 与文献方向                               | 问题                                                    |
| --------- | --------------------- | ----------------------------------- | ----------------------------------------------------- |
| `HIGH52`  | **−0.0093** (t=−2.29) | 文献（George-Hwang 2004）预期**正向**       | 方向相反，靠 CH-4 调整后 α 才转正（+0.518，t=2.16）                  |
| `RES_MOM` | **−0.0078** (t=−2.22) | 文献（Blitz-Huij-Martens 2011）预期**正向** | 方向相反，且**样本外负得更明显**（IC −0.0158，t=−2.10）                |
| `BETA`    | +0.0183 (t=5.11)      | 方向正确，但                              | 多空年化仅 1.3%（t=0.66）；**CH-4 后 t 从 −0.03 到 −0.77，被完全吸收** |

**这三条不是"否定结论"，而是"事后解释"**：它们入选是因为通过了机械门槛，而不是因为它们独立地强。诚实的说法是——它们更像是**控制变量**而非**选股信号**。多变量 Fama-MacBeth 的结果支持这个解读（见第七节）：`HIGH52` 的联合权重是**显著正**的 (+0.0179，t=2.12)，说明它剔除其他 16 个因子的暴露后确实有正向贡献；而 `MAX5`、`CO_SKEW`、`BETA` 的联合权重是**负的**，即它们的独立成分是冗余的。

## 三、17 个最终因子：理论来源与模型

预处理流水线对**每一个**因子统一执行四步（这是截面因子研究里最容易被跳过、却最影响结论的一步）：

```
① 股票池掩码（剔除 ST / 次新 / 停牌 / 涨停）
② MAD 去极值：中位数 ± 3 × 1.4826 × MAD
   —— 用 MAD 而非 3σ，因为 A 股收益厚尾会污染 σ 本身，导致截断失效
③ 行业 + 市值中性化：逐日横截面回归 factor_i = a + Σ b_k·Industry_k + c·ln(流通市值) + e_i，取残差 e_i
   —— 剔除"因子只是行业的代理"或"只是小市值的代理"这类伪显著
   —— 用 Frisch-Waugh-Lovell 拆成两步一元残差化，全 A 面板从约 40 分钟降到几秒
④ 横截面 z-score 标准化
```

### 因子 1–15

> （即样本内 |NW t| 降序，见第二节的筛选规则），唯一的例外是 `COMMOVE` 与  
> `TURN_SHOCK` —— 这两个 B 层因子被单独放到最后（第 16、17 节）重点说明，  
> 因为它们是"截面联动"这个方向的实证支撑。
>
> **层级归属**（与编号顺序无关，请以本表为准）：
>
> - **A 层（经典异象）候选 15 个** → 入选 11 个：`TURN` `MAX5` `ILLIQ` `REV_1W` `ISKEW` `IVOL` `CO_SKEW` `BETA` `REV_LT` `SIZE` `HIGH52`
> - **B 层（截面联动 / 微观结构类）候选 9 个** → 入选 6 个：`INTRADAY` `OVERNIGHT` `LEAD_LAG` `RES_MOM` `COMMOVE` `TURN_SHOCK`
> - 合计 **17 个**。B 层落选的 3 个（`IND_MOM` `SPILLOVER` `DIVERGENCE`）见第五节。

#### 1. `TURN` 换手率（负向）　★最强单因子

|        |                                                                                                                            |
| ------ | -------------------------------------------------------------------------------------------------------------------------- |
| **文献** | Datar, Naik & Radcliffe (1998), *Liquidity and stock returns: An alternative test*, Journal of Financial Markets           |
| **模型** | 在 Fama-French 三因子之外加入换手率作为第四个解释变量做截面回归，发现换手率系数**显著为负**。作者的解读是流动性溢价：高换手 = 高流动性 = 低预期收益。后续文献（如 Liu 2006）补充为"换手率是投资者异质信念的代理"。 |
| **实现** | `−mean(换手率, 21日)`                                                                                                          |
| **实测** | RankIC **0.0698**，NW t **22.39**，ICIR **3.21**，IC胜率 81.7%，多空年化 **28.2%**（t=15.91），单调性 1.00                                 |

**这是全部 24 个因子里最强的。** 与 Jansen, Swinkels & Zhou (2021) 关于中国市场的结论一致——在他们检验的全部交易类异象中，异常换手率是**唯一**在市值加权下仍然显著的。

---

#### 2. `MAX5` 彩票效应（负向）

|        |                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| **文献** | Bali, Cakici & Whitelaw (2011), *Maxing out: Stocks as lotteries and the cross-section of expected returns*, JFE         |
| **模型** | 定义 `MAX = 过去一个月日收益最大的 5 天均值`（原文同时检验了 1 天与 5 天两种口径），在控制规模、BM、动量、反转、流动性、偏度后，MAX 与未来收益**显著负相关**。机制是投资者对彩票型收益的偏好导致这类股票被过度定价。 |
| **实现** | `−rolling_topk_mean(日收益, 21日, 5)`                                                                                        |
| **实测** | RankIC 0.0602，t 19.10，ICIR 2.73，多空年化 19.7%（t=10.77），单调性 0.99                                                             |

**⚠️ 弱点**：多变量 FM 下权重变成 **−0.0097（t=−1.11）**——单变量 IC 高达 0.060，但联合权重为负且不显著，说明它的独立信息已被 `IVOL`/`TURN` 吸收。这是"单因子强 ≠ 组合有用"的教科书例子。

---

#### 3. `INTRADAY` 日内收益反转（负向）

|        |                                                                                                                                                             |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文献** | Lou, Polk & Skouras (2019), *A tug of war: Overnight versus intraday expected returns*, JFE                                                                 |
| **模型** | 把日收益拆成两段：**隔夜段** `close_{t−1} → open_t` 与**日内段** `open_t → close_t`。原文的核心发现是这两段对未来收益的预测方向**相反**：隔夜收益正相关（散户情绪），日内收益负相关（机构价格压力的临时成分）。这是一个"拉锯"模型，而不是传统的日频收益动量。 |
| **实现** | `−rolling_compound(close_t/open_t − 1, 21日)`                                                                                                                |
| **实测** | RankIC 0.0531，t 18.73，ICIR 2.63，多空年化 24.0%（t=13.61），单调性 1.00                                                                                                |

与 `REV_1M` 相关 0.84（见第二节），说明它捕捉的正是 A 股的短期反转主体。

---

#### 4. `ILLIQ` Amihud 非流动性（正向）

|        |                                                                                                                     |     |                                                                                     |
| ------ | ------------------------------------------------------------------------------------------------------------------- | --- | ----------------------------------------------------------------------------------- |
| **文献** | Amihud (2002), *Illiquidity and stock returns: cross-section and time-series effects*, Journal of Financial Markets |     |                                                                                     |
| **模型** | \`ILLIQ = 日均(                                                                                                       | 日收益 | / 日成交额)\`。这是"价格冲击成本"的直接度量：同样一笔成交额推动价格变动越大，流动性越差。原文的时序与截面回归都显示非流动性溢价为正——越不流动，预期收益越高。 |
| **实现** | \`log1p(mean(                                                                                                       | ret | /amount, 21日) × 1e8)\`，取对数是因为原始分布极度右偏                                               |
| **实测** | RankIC 0.0436，t 18.11，ICIR 2.59，多空年化 19.4%（t=15.03），单调性 1.00                                                        |     |                                                                                     |

**⚠️ 注意**：多变量 FM 下权重骤降到 **0.0023（t=0.44）**——绝大部分信息被 `TURN` 吸收（两者都是流动性维度）。但在 CH-4 调整后它是**第 7 强**的因子（α +0.550%/月，t=4.25）。

#### 5. `REV_1W` 周度反转（负向）

|        |                                                                                                        |
| ------ | ------------------------------------------------------------------------------------------------------ |
| **文献** | Lehmann (1990), *Fads, martingales, and market efficiency*, QJE                                        |
| **模型** | 检验周度（而非月度）反转：构造"上周输家 − 上周赢家"组合，发现其获得显著正收益。Lehmann 的解释是买卖价差与流动性提供者的补偿，而非理性风险溢价——即这是一个**微观结构效应**，不是风险补偿。 |
| **实现** | `−(close_t / close_{t−5} − 1)`                                                                         |
| **实测** | RankIC 0.0316，t 14.14，ICIR 1.67，多空年化 14.9%（t=10.66），单调性 0.82                                           |

**CH-4 后 α +0.586%/月（t=3.12）**，是第 6 强。

---

#### 6. `ISKEW` 特质偏度（负向）

|        |                                                                                                                           |
| ------ | ------------------------------------------------------------------------------------------------------------------------- |
| **文献** | Harvey & Siddique (2000), *Conditional skewness in asset pricing tests*, Journal of Finance                               |
| **模型** | 在传统 CAPM/FF 检验中加入**协偏度**作为第三个风险因子，发现它被显著定价。其经济含义是：投资者偏好正偏度（小幅亏损、大额盈利的可能性），因此正偏度资产被高估、预期收益更低。`ISKEW`（个股自身收益偏度）是这个偏好最直接的代理。 |
| **实现** | `−skew(日收益, 60日)`                                                                                                         |
| **实测** | RankIC 0.0241，t 14.04，ICIR 2.01，多空年化 8.3%（t=8.13），单调性 0.98                                                                |

IC 水平不高，但**极其稳定**（ICIR 2.01、样本外 IC 0.0268 反而更高）。

---

#### 7. `IVOL` 特质波动率（负向）

|        |                                                                                                                                               |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **文献** | Ang, Hodrick, Xing & Zhang (2006), *The cross-section of volatility and expected returns*, Journal of Finance                                 |
| **模型** | 先用 Fama-French 三因子回归取残差标准差得到 IVOL，再做截面回归：**IVOL 最高的五分位组合，未来收益比最低五分位低 1.06%/月**。这个结果在控制规模、BM、动量、流动性后依然存在，因此被称为"特质波动率之谜"——按标准理论，特质风险应当**不被定价**。 |
| **实现** | 用滚动矩公式免去逐股回归：`IVOL² = Var(r) − Cov(r, r_m)² / Var(r_m)`                                                                                       |
| **实测** | RankIC **0.0519**（第 6 高），t 12.63，ICIR 1.86，多空年化 16.4%，单调性 1.00                                                                                |

**⚠️ 特点**：IC 水平很高但 ICIR 只有 1.86——IC 的**波动**大。样本外 IC 0.0638（比样本内还高）。

---

#### 8. `LEAD_LAG` 领先滞后（负向）

|        |                                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------------------ |
| **文献** | Lo & MacKinlay (1990), *When are contrarian profits due to stock market overreaction?*, RFS                  |
| **模型** | 原文分解反转利润的来源，发现**很大一部分不是来自过度反应，而是来自"领先—滞后"结构**：大市值/高流动性股票对市场信息反应快，小盘股滞后。因此对`滞后一期的市场收益`敏感度高的股票（反应慢）在未来存在补涨/补跌。 |
| **实现** | `−Cov(r_i, r_m,t−1) / Var(r_m)`，即对滞后市场收益的回归系数取负                                                              |
| **实测** | RankIC 0.0153，t 7.23，ICIR 1.06，多空年化 3.2%，单调性 0.52                                                            |

**⚠️ 最明显的样本内→样本外衰减**：样本外 IC **0.0018（t=0.40）**，几乎归零。这个因子基本可以认为是样本内产物。

---

#### 9. `OVERNIGHT` 隔夜收益（正向）

|        |                                                                                        |
| ------ | -------------------------------------------------------------------------------------- |
| **文献** | Lou, Polk & Skouras (2019)，同 `INTRADAY`                                                |
| **模型** | 同一篇论文的另一半：隔夜段（`close_{t−1} → open_t`）与未来收益**正相关**。原文的解释是隔夜交易以散户为主，隔夜收益包含了尚未被套利消除的乐观情绪。 |
| **实现** | `rolling_compound(open_t / close_{t−1} − 1, 21日)`                                      |
| **实测** | RankIC 0.0168，t 10.74，ICIR 1.49，多空年化 6.9%，单调性 0.48（**分层不单调**）                          |

样本外 IC **0.0286（t=9.93）比样本内高**，CH-4 后 α +0.616%/月（t=4.25），第 4 强。**这是 17 个因子里"样本内外一致性"最好的之一。**

---

#### 10. `CO_SKEW` 协偏度（负向）

|        |                                                                                                         |
| ------ | ------------------------------------------------------------------------------------------------------- |
| **文献** | Harvey & Siddique (2000)，同 `ISKEW`                                                                      |
| **模型** | 与 `ISKEW` 的区别在于：`ISKEW` 是个股收益自身的偏度（**可分散**），`CO_SKEW` 是个股收益与**市场收益**的协偏度（**不可分散**，属系统性风险）。理论上只有后者应当被定价。 |
| **实现** | `−E[(r_i − μ_i)(r_m − μ_m)²] / (σ_i · σ_m²)`，分子按定义展开为滚动矩的组合，避免逐日回归                                      |
| **实测** | RankIC 0.0149，t 5.97，ICIR 0.90，多空年化 6.7%，单调性 0.94                                                       |

**⚠️ 弱点**：多变量 FM 下权重 **−0.0068（t=−1.27）**，与 `ISKEW` 共同提供偏度维度后成为冗余。

---

#### 11. `BETA` 市场 beta（负向，BAB）

|        |                                                                                                                            |
| ------ | -------------------------------------------------------------------------------------------------------------------------- |
| **文献** | Frazzini & Pedersen (2014), *Betting against beta*, JFE                                                                    |
| **模型** | 核心是**杠杆约束**：一部分投资者（如公募基金）不能加杠杆，为了追求高收益只能去买高 beta 资产，把高 beta 推高、把低 beta 压低。因此构造"做多低 beta / 做空高 beta"的 beta 中性组合可以获得正 alpha。 |
| **实现** | `−Cov(r_i, r_m)/Var(r_m)`，252 日滚动                                                                                          |
| **实测** | RankIC 0.0183，t 5.11，但**多空年化只有 1.3%（t=0.66）**，单调性 0.35                                                                     |

**⚠️ 这是 17 个里最弱的一个**：样本外 IC 0.0119（t=1.33），多空 **−10.46%**；CH-4 存活检验中原始 t=−0.03、CH-4 后 t=−0.77——**完全不被定价**。与 Jansen-Swinkels-Zhou (2021) 关于中国市场 BETA 不显著的结论一致。它入选纯粹是 `|IC t|>2` 门槛的机械结果。

---

#### 12. `REV_LT` 长期反转（负向）

|        |                                                                                             |
| ------ | ------------------------------------------------------------------------------------------- |
| **文献** | De Bondt & Thaler (1985), *Does the stock market overreact?*, Journal of Finance            |
| **模型** | 按过去 3 年收益排序构造赢家/输家组合，发现**输家组合在随后 3 年显著跑赢赢家组合**（约 25%）。作者归因于投资者对信息的**过度反应**。这是行为金融学的奠基性实证之一。 |
| **实现** | `−(close_{t−252} / close_{t−756} − 1)`                                                      |
| **实测** | RankIC 仅 0.0093，t 3.79，ICIR 0.63，多空年化 6.0%                                                  |

**⚠️ 有趣的反转**：CH-3 后 α 从 0.4125 微升到 0.4147，而 **CH-4 后跳到 +0.5291（t=4.26）**——调整风险模型后反而更强。原因是它带有低 SMB/低 VMG 的暴露，剔除后残余 α 更清晰。

#### 13. `SIZE` 规模（负向）

|        |                                                                                       |
| ------ | ------------------------------------------------------------------------------------- |
| **文献** | Banz (1981), *The relationship between return and market value of common stocks*, JFE |
| **模型** | 最早的截面异象：把 NYSE 股票按市值分组，发现**最小市值组的风险调整后收益显著高于其他组**，且这个"规模效应"不能被当时的 CAPM beta 解释。       |
| **实现** | `−ln(流通市值)`                                                                           |
| **实测** | RankIC 0.0100，t 2.67，ICIR 0.39，单调性 0.99                                               |

**⚠️ 已被风险模型基本吸收**：CH-3 后 t 从 2.02 升到 2.26，但 **α 从 0.434 掉到 0.1735**，`r²` 贡献 0.866——即"小市值溢价"在中国主要就是 SMB 因子本身。这是**预期之内**的结果，不算问题，但说明 `SIZE` 在组合中主要起风格暴露的作用。

#### 14. `HIGH52` 52 周高点（正向，但实测方向相反）

|        |                                                                                                                             |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| **文献** | George & Hwang (2004), *The 52-week high and momentum investing*, Journal of Finance                                        |
| **模型** | 用 `当前价 / 过去 52 周最高价` 作为动量的替代度量。原文发现这个比率**完全解释**了传统动量利润（Jegadeesh-Titman 的赢家组合在这个指标上得分最高），因为投资者以 52 周高点为**锚**，接近高点时对好消息反应不足。 |
| **实现** | `close / max(high, 252日)`                                                                                                   |
| **实测** | RankIC **−0.0093（t=−2.29）**，即**越接近 52 周高点，未来收益越低**——与美股方向相反。多空年化 −4.9%。样本外 IC 仍为负（−0.0017，t=−0.20）                          |

#### 15. `RES_MOM` 残差动量（正向，但实测方向相反）

|        |                                                                                                                          |
| ------ | ------------------------------------------------------------------------------------------------------------------------ |
| **文献** | Blitz, Huij & Martens (2011), *Residual momentum*, JFE                                                                   |
| **模型** | 传统动量组合带有**时变的 beta 暴露**（赢家组合在上涨期 beta 高），这被认为是动量崩盘的来源。原文的解决方案是：先做市场模型回归取残差，再对**残差收益**排序构造动量组合。结果是残差动量的夏普约为传统动量的两倍，且回撤更小。 |
| **实现** | `sum(市场模型残差, 231日).shift(21)`                                                                                            |
| **实测** | RankIC **−0.0078（t=−2.22）**，多空年化 **0.3%（t=0.16）**，单调性 0.10；样本外 IC **−0.0158（t=−2.10）**                                   |

**这是 17 个里最应该被质疑的入选因子。** 三点问题叠加：

1. 方向与文献相反（美股正、A 股负）；
2. 多空组合 t=0.16，几乎毫无区分度（多空年化 0.3%）；
3. **样本外的反向信号比样本内更强**：IC 从 −0.0078 放大到 **−0.0158**（绝对值翻倍），t 从 −2.22 到 −2.10 —— 在只有 3.6 年的样本外窗口里保持同量级的反向显著性，说明这不是样本内的偶发。

### 因子 16–17：B 层截面联动类的核心两个

> 这两个因子按 `keep` 顺序本应排在前面（`COMMOVE` 样本内 t=17.61 位列第 5），  
> 单独放到最后是因为它们承载了本策略对"**截面联动类因子**"这一要求的实证回答。

这一层是**按你的要求专门构建的**：因子不来自个股自身特征，而来自**个股与其它股票的截面关系**。理论依据是两个方向——（i）行业/风格共同因子的定价，（ii）信息在关联股票间的**渐进扩散**（渐进信息扩散假说，Hong & Stein 1999；Hong, Torous & Valkanov 2007）。

#### 16. `COMMOVE` 联动度（正向）　★ CH-4 后最强因子

|            |                                                                                                                                                                       |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### 4.1 三个最重要的读法

**① 样本内外符号一致性（已逐条核算）**：24 个因子中，样本内 IC ≥ 0 的有 **18 个，样本外无一翻负**；样本内 IC < 0 的有 **6 个，样本外只有 1 个翻正**（`PV_CORR`，从 −0.0044 到 +0.0031）。**24 个因子里只有 1 个符号翻转**——这是"因子捕捉的是真实结构而非噪声"最直接的间接证据。同时它也说明 A 股因子的符号结构在 2010-2022 与 2023-2026 两段之间是**稳定**的。

**② 样本内外衰减最严重的两个**：`LEAD_LAG`（NW t 从 7.23 掉到 **0.40**，IC 从 0.0153 掉到 0.0018）和 `PV_CORR`（唯一符号翻转者）。这两个都属"微观结构/领先滞后"类，在 A 股市场结构快速变化（2010 年后机构化、2015 年后程序化交易普及）的背景下失效，逻辑上说得通。

### 4.2 因子层面的多重检验校正（BH-FDR）

主程序对 24 个因子的 IC t 值计算双侧 p 值，再用 Benjamini-Hochberg 控制 FDR=5%。未校正时 |t|>2 的因子有 19 个；FDR 校正后通过的是 IC 最强的那一批（`TURN`/`MAX5`/`INTRADAY`/`ILLIQ`/`COMMOVE`/`REV_1M` 等）。**这一步与组合层面的 Deflated Sharpe 是互补的**——前者校正"挑了 24 个因子"，后者校正"挑了 114 个策略配置"。

### 6.1 从 5 次失败中提炼出的规律

**新增因子能否改善组合，取决于两个条件的交集：**

```
        IC 足够高
            │
   ① CGO    │   ③ COMMOVE（唯一成功）
   ABN_TURN │
   VTURN    │
────────────┼────────────── 与已有因子的正交性
            │
   ② BIZ_LINK│   ④ GEO_LINK
   （IC=0）  │   （正交但 IC 太低）
            │
```

- **象限 ①（IC 高但同族）**：`CGO`/`ABN_TURN`/`VTURN` —— 数据上显著，但信息已被现有因子覆盖
- **象限 ④（正交但 IC 低）**：`GEO_LINK`/`BIZ_LINK` —— 提供的是**新维度但太弱**的噪声
- **象限 ③（既正交又强）**：只有 `COMMOVE` —— 这正是本策略里"截面联动"方向的价值所在

**结论：只有"既与现有因子正交、IC 又足够高"的因子才有用。在现有数据源下，24 个基础因子之外我没有再找到第二个这样的因子。**

## 七、多因子合成：方法与结果

### 7.1 合成方法

```
合成得分 = 已入选因子「预处理后 z-score」的等权平均
           （分母为当日该股票的有效因子个数，逐股逐日计算，避免缺失值导致权重失衡）
```

**为什么是等权，而不是按 IC 或按 alpha 加权？** 这是实测比较过三种方案后的结论（样本外，11 个调仓相位平均）：

| 合成方法             | 多头夏普      | 多空夏普      | 多头最大回撤      | 判定            |
| ---------------- | --------- | --------- | ----------- | ------------- |
| **等权（采用）**       | **0.859** | 1.201     | **−26.25%** | 基准            |
| FM 多变量加权（λ=0.05） | 0.672     | **1.333** | −34.43%     | 多空改善、**多头恶化** |
| CH-4 alpha 加权    | 0.670     | 1.067     | —           | 两者均不优于等权      |

**FM 加权让多空组合变好（1.201→1.333）却让多头组合大幅变差（0.859→0.672）**，原因是 FM 权重把大量权重给了空头端有效的因子，而多头端的实现依赖不同的因子结构。由于**可实盘的是多头**，最终采用等权。

### 7.2 多变量 FM 权重（等权方案的诊断，非最终权重）

这是理解"哪些因子真正有独立贡献"的关键表。权重来自 Fama-MacBeth 两步法（1973）的第二步，t 值经 Newey-West 修正：

| 因子          | 联合权重        | NW t     | 解读                                      |
| ----------- | ----------- | -------- | --------------------------------------- |
| **TURN**    | **0.0625**  | **7.05** | 绝对主导，占全部正权重的一半以上                        |
| INTRADAY    | 0.0343      | 3.56     | 第 2 重要                                  |
| REV_1W      | 0.0262      | 3.31     | 独立于 INTRADAY（相关仅 0.38）                  |
| IVOL        | 0.0177      | 2.19     |                                         |
| COMMOVE     | 0.0121      | 2.20     | 联动类唯一显著正权重                              |
| HIGH52      | 0.0179      | 2.12     | **显著正**（尽管单变量 IC 为负）                    |
| TURN_SHOCK  | 0.0094      | 1.77     |                                         |
| RES_MOM     | 0.0135      | 1.55     | 不显著                                     |
| ISKEW       | 0.0052      | 1.40     |                                         |
| LEAD_LAG    | 0.0050      | 1.06     |                                         |
| REV_LT      | 0.0033      | 0.61     |                                         |

### 8.2 基础显著性检验（样本外）

| 组合 | 样本年数 | **Newey-West t** (lag=5) | 夏普    | **PSR** | 自助 95% CI    | P(夏普>0) |

**读法**：`NW t` 已修正收益自相关；`PSR`（Probabilistic Sharpe Ratio）是修正偏度与厚尾后"真实夏普 > 0"的概率；自助区间用平稳分块 bootstrap（B=2000，block=21）得到。

**多头 NW t=1.942，略低于 1.96 的 5% 门槛。** 这不是策略问题，而是样本长度问题：在 `t = 夏普 × √年数` 的关系下，**3.60 年样本要在 5% 水平显著，需要年化夏普 > 1.03**。多空组合 t=2.292 已显著。

### 8.3 ★ 关键补充：CH-4 alpha（风险模型调整后）

只报原始 t 值是不够的。Hou, Qiao & Zhang (2023) 的证据是：426 个异象中 98 个市值加权显著，经 CH-3 调整后只剩 16 个，**CH-4 后为 0**。因此必须报风险模型调整后的 alpha。

按 Liu, Stambaugh & Yuan (2019, JFE) 的**精确配方**自建 CH-3 / CH-4（MKT + SMB + VMG[EP 口径，**不是** BM] + PMO[异常换手率]，股票池剔除最小 30%，市值加权）：

| 组合 / 区间      | **CH-4 α（年化）** | **t**    | β_MKT  | β_SMB  | β_VMG | R²    |
| ------------ | -------------- | -------- | ------ | ------ | ----- | ----- |
| 多头 / 全样本     | **+8.79%**     | **5.77** | 0.923  | −0.711 | 0.098 | 0.919 |
| 多头 / 样本内     | +7.07%         | 4.29     | 0.940  | −0.694 | 0.132 | 0.924 |
| **多头 / 样本外** | **+12.86%**    | **4.29** | 0.878  | −0.819 | 0.042 | 0.913 |
| 多空 / 全样本     | **+11.93%**    | **5.19** | −0.071 | −0.054 | 0.419 | 0.635 |
| **多空 / 样本外** | **+13.18%**    | **4.05** | −0.110 | −0.141 | 0.511 | 0.885 |

**结论：alpha 不是规模/价值 beta 的伪装。** 控制中国市场三/四因子后，样本外多头 alpha 仍有 **+12.86%/年（t=4.29）**。

> 注：`strategy_ch3_reg.json` 中对样本外月度回归给出 +10.34%（t=4.22），与上表 +12.86% 的差异来自回归所用的样本区间端点定义不同。两者都在 4 倍标准误以上，结论稳健。

**CH-3 解释了多头组合月度方差的 92.7%**（R²=0.9271）——这条数字同时说明了本策略最大的结构性约束：**风险由单一市场因子主导，因此任何降风险手段都会同比例降收益**（六类手段实测无效，见 `最终交付报告.md` 第四节）。

### 8.6 ★ 不依赖"试验次数 N"的检验：安慰剂检验

DSR 的根本弱点是它需要一个人为自定的 N。**安慰剂检验不需要**：把截面得分随机打乱 200 次（破坏因子与股票的对应关系，保留全部其他结构），重新跑完整策略，看真实结果在这 200 个"假策略"分布里的位置。

| 指标              | 真实值    | 安慰剂均值  | 安慰剂最大值 | **z 值**    | **p 值**    |
| --------------- | ------ | ------ | ------ | ---------- | ---------- |
| 全样本夏普           | 0.669  | 0.158  | 0.294  | **+10.11** | **0.0000** |
| 样本外夏普           | 1.017  | 0.261  | 0.611  | **+6.33**  | **0.0000** |
| 近 24 月夏普        | 1.720  | 0.957  | 1.455  | **+4.67**  | **0.0000** |
| CH-4 α 全样本（%/年） | +8.45  | −0.384 | +4.37  | **+5.33**  | **0.0000** |
| CH-4 α 样本外（%/年） | +12.16 | −0.707 | +9.72  | **+3.79**  | **0.0000** |

**五项指标全部 p=0.0000（200 次抽取无一超过真实值）。**

**零假设的自洽性验证**：打乱得分后，CH-4 α 的均值落在 **−0.384%（全样本）/ −0.707%（样本外）**——几乎正好为 0。这说明安慰剂构造正确，没有引入系统性偏差。

**⚠️ 安慰剂检验同时揭示了一个必须说清的细节**：近 24 个月窗口下，**安慰剂夏普的均值是 0.957**（95 分位 1.221）。也就是说，1.720 里面约有 **0.96 来自"这两年随便找 50 只股票本来就容易赚"**（2024-2026 的小盘/主题行情），真正的选股超额是 **+0.76**。这一点比任何 DSR 数字都更能说明"短窗口高夏普"该怎么读。

**安慰剂检验 vs DSR**：安慰剂检验通过（p<0.005），DSR 本族口径中位通过（0.9567）、最差相位边缘（0.9310）。**两者并不矛盾**——它们回答的是不同问题：DSR 问"考虑我试了 114 次，这个夏普还够高吗"；安慰剂问"如果把因子完全打乱，还能得到这个结果吗"。**安慰剂检验是本报告的首选判据，因为它不需要自定 N。**

**关于"基金近一年夏普 2.6"的统计说明**：夏普的近似标准误（Lo 2002）`se ≈ sqrt((1 + SR²/2)/n)`，n 为年数。12 个月时 se ≈ ±1.0~1.2，**近 12 个月多头夏普 0.91 的 95% 区间是 [−1.42, 3.24]——2.6 落在区间内部**。因此单年夏普无论 0.9 还是 2.6 都不能作为策略优劣的判据。

### 8.9 交易成本敏感性（样本外）

| 成本倍数     | 多头年化   | 多头夏普  | 多空年化   | 多空夏普  |
| -------- | ------ | ----- | ------ | ----- |
| 1.0×（基准） | 21.53% | 1.018 | 14.83% | 1.080 |
| 2.0×     | 18.98% | 0.906 | 11.42% | 0.816 |
| 3.0×     | 16.49% | 0.793 | 8.11%  | 0.554 |

**成本翻三倍后多头夏普仍有 0.793**——策略不依赖低成本假设。年化换手：**相位 0 为 1407%**，11 相位平均 1512%；未加缓冲区的原版为 1771%（相位平均）。

## 九、结论与已知弱点汇总

### 9.1 三条主要结论

1. **等权合成 17 个因子的多头组合，在样本外 3.6 年取得夏普 1.017、CH-4 调整后 alpha +12.86%/年（t=4.29）**，且安慰剂检验五项指标 p=0.0000。alpha 不是风格 beta 的伪装。
2. **因子族的性质决定了它能否通过风险模型检验。** 全部因子均为交易/价量类，16/21 在 CH-4 后存活；而 HQZ 的会计类异象是 0/426。**结构差异而非方法差异。**
3. **"截面联动"方向只成功了一个因子：`COMMOVE`。** 它是 CH-4 后最强的因子（α +0.652%/月，t=6.37），也是样本外 t 值最高的（13.22）。其余四个联动类因子（`IND_MOM`/`SPILLOVER`/`DIVERGENCE`/`GEO_LINK`/`BIZ_LINK`）全部失败。

### 9.2 必须坦白的弱点

| #  | 弱点                                  | 具体表现                                                 | 影响                           |
| -- | ----------------------------------- | ---------------------------------------------------- | ---------------------------- |
| 1  | **入选门槛对符号不敏感**                      | `HIGH52`（IC −0.0093）、`RES_MOM`（IC −0.0078）方向与文献相反仍入选 | 它们更像控制变量而非选股信号，靠 CH-4 事后解释   |
| 2  | **`BETA` 入选但完全无效**                  | 多空 t=0.66，CH-4 后 t=−0.77                             | 占用 1/17 权重，纯属门槛的机械结果         |
| 3  | **等权合成存在已知低效**                      | 3 个因子联合权重为负、4 个近零，仍给同样 1/17 权重                       | 未解决；FM 加权在多头端更差，故未替换         |
| 4  | **`IND_MOM` 与 `SPILLOVER` 函数体逐字相同** | 同一因子注册两次                                             | 虚增试验次数、抬高 DSR 门槛；计数时应只算一次    |
| 5  | **`LEAD_LAG` 样本外基本失效**              | IC t 从 7.23 掉到 0.40                                  | 保留在组合中贡献噪声                   |
| 6  | **`ISKEW`/`CO_SKEW` 与 `MAX5` 互相冗余** | `MAX5` 联合权重转负                                        | 三者合计占 3/17 权重但只提供约 1 个维度的信息  |
| 7  | **样本外仅 3.60 年**                     | 多头 NW t=1.942 略低于 1.96                               | 不是策略问题而是样本长度问题（需夏普>1.03 才显著） |
| 8  | **多空组合依赖融券**                        | A 股券源有限、成本高                                          | 多空夏普 1.080 仅学术口径，**可实盘的是多头** |
| 9  | **涨跌停卖出限制未建模**                      | 调仓日跌停按可成交处理                                          | 略微高估业绩                       |
| 10 | **行业分类是当前快照**                       | 非时点数据                                                | 早期年份存在分类前视；估计 5~10% 误分类      |
| 11 | **CH-3/CH-4 用监管披露截止日**              | 保守（无前视），但比实际披露晚                                      | 略微低估 alpha                   |
| 12 | **146 只已退市股票缺失**                    | 新浪数据源侧缺失                                             | 残余幸存者偏差                      |

### 9.3 建议的后续动作（按优先级）

1. **把 `RES_MOM`、`HIGH52`、`BETA` 移出因子池重跑**——预期多头夏普不变或略微改善（三者合计权重 1/17，其中两个边际贡献可疑）。这会同时把试验次数从 114 降到约 90，DSR 门槛略微下降。
2. **修正 `IND_MOM`/`SPILLOVER` 重复**——纯计数问题，无业绩影响，但影响 DSR 的正确性。
3. **对等权方案做一次"权重下界裁剪"实验**——把联合权重近零的 4 个因子降权而非等权，看多头是否改善。此前只试过 FM 全量加权（更差），没试过"只降零权重因子"的中间方案。
4. **唯一有文献依据的未走路径**：国家统计局投入产出表（约 149 个部门）→ Menzly & Ozbas (2010) 纵向关联；以及分析师/北向资金数据（需接 Wind，连接器市场里有 `wind-stock-data`）。**业务文本路径已可排除**（`BIZ_LINK` 即使带前视优势 IC 仍为零）。
