## 四、核心风险结论：为什么长窗口下 MaxDD<15% 对多头不可达

> ⚠️ **本节结论已被第十节修正。** 本节论证的是「3.6 年及更长窗口」下多头无法同时满足  
> Sharpe>1.2 与 MaxDD<15% —— 该论证成立。但在 **24 个月窗口**上，多头实测  
> Sharpe 1.592、MaxDD −12.85%、Calmar 2.829，**三项全部达标且 11 个相位无一例外**。  
> 正确表述应为：**目标在 24 个月窗口上可达，在 36 个月/全样本窗口上不可达**，  
> 差别在于 2023-07~2024-02 那次回撤是否落在窗口内。

### 4.1 回撤归因

用滞后 1 日的 252 日滚动 β 对市场分解：

| 回撤区间                        | 深度          | 同期市场    | β 贡献    | **残差（自身暴露）** |
| --------------------------- | ----------- | ------- | ------- | ------------ |
| 2015-06-15 → 2018-10-18     | **−50.21%** | −49.56% | −47.48% | −2.73%       |
| 2011-04-22 → 2012-12-03     | −36.84%     | −34.48% | −33.03% | −3.81%       |
| **2023-07-26 → 2024-02-07** | **−25.49%** | −16.28% | −15.60% | **−9.89%**   |

- 大级别崩盘**几乎全是市场 beta**（2015 年 −47.5pp / −50.2pp）
- 样本外那次 −25.49% 中有 **−9.89pp 来自自身的小盘/非流动性暴露**（2024 年 1-2 月微盘股流动性踩踏）

### 4.2 收益分解（CH-4，月度）

| 来源        | β      | 因子月均    | 贡献                    |
| --------- | ------ | ------- | --------------------- |
| **α（选股）** | —      | —       | **+0.595%**           |
| 市场 MKT    | 0.924  | +0.357% | +0.330%               |
| 规模 SMB    | −0.722 | −0.413% | +0.298%               |
| 价值 VMG    | 0.108  | +0.388% | +0.042%               |
| 合计        |        |         | +1.265% ≈ 实测 1.303% ✓ |

**CH-3 解释多头组合月度方差的 92.7%。** 残差波动 σ_ε ≈ 5.2%/年，  
alpha ≈ +10~13%/年 → **alpha 单独看夏普约 2.0**。

### 4.3 为什么不能靠调 β 把夏普做上去

两条降 β 的路径，都已实测：

| 路径                 | 结果                                                         |
| ------------------ | ---------------------------------------------------------- |
| **持有现金降杠杆**        | 收益与回撤**同比例**缩放 → **夏普与 Calmar 严格不变**（算术恒等，非经验结论）           |
| **换低 β 股票**（β 目标化） | β 0.90→0.63 有效，但**收益与回撤近乎 1:1 交换，Calmar 从 0.828 降到 0.723** |
| **组合层面市值约束**       | 把平均市值分位精确打到 0.50，**β_SMB 一动不动仍是 −0.797**                   |
| **股指期货对冲**         | 零基差时夏普都不升；A 股 IC/IM 常年贴水，基差 −6% 时夏普降到 0.135                |

**β_SMB = −0.72 不是可以用约束拧掉的旋钮**，而是策略经济性质的必然结果：  
长期低波动、低换手、非流动性股票天然与大盘/低波复合体同步。

**结论：在"长期只做多、不做空股指期货"的约束下，Sharpe>1.2 与 MaxDD<15% 不可兼得。**  
多头组合 β≈0.92，A 股在 2015/2018/2024 式下跌中必然出现 25%~50% 回撤。

## 五、★ 第四轮：因子按风险调整后 α 加权（**结论见第七节的修正**）

### 6.1 做法

CH-4 存活检验给出了每个因子的风险调整后 α。据此给因子**非等权**加权：

```
ω_i ∝ max(α_i^{CH-4}, 0)
```

**★ 前视控制（关键）**：第一版直接用全样本（2010-2026，含样本外）估计的 α 作权重，  
得到 OOS 夏普 1.803 —— 但那是前视。改为**只用样本内 2010-2022（156 个月）**&#x91CD;新估计  
α 再加权，OOS 夏普降到 **1.327**。**前视代价 0.48 夏普**，必须披露。

### 6.4 多头为何没跟上

按**价差 α** 加权让多头变差（OOS 0.859→0.709）；改按**多头腿单独的 α** 加权后  
仅 0.859→0.867（+0.008，几乎无效）。原因是 **Stambaugh-Yu-Yuan (2012) 的核心发现**：  
情绪/异象效应 94% 来自空头腿，**多头腿 t=0.62（为零）**。  
本策略实测同样如此 —— 多头腿 α 全部挤在 +0.67%~~+1.35%/月 的窄区间，  
区分度远低于价差 α（−0.04%~~+1.36%），无法据此有效加权。

**多头口径的结论：因子加权救不了它，等权已是最优。**

### 6.2 结论：`Sharpe > 1.2` 对 A 股多头不现实

`Sharpe > 1.2` 相当于指数的 **3~8 倍**。要在 19% 波动下达到 1.2，需要年化约 **24.8%**  
（当前 21.53%），即**再增加约 3.3pp 的纯 alpha** —— 相当于把现有 alpha 提高约 25%。  
在现有数据（日频 OHLCV + 换手率 + 流通市值 + 行业）下，这需要**引入全新信息源**，  
而不是继续调参。

### 6.3 风险模型优化（最后一个未试过的杠杆）同样失败

此前一直用等权，从未利用协方差信息。本轮补做标准均值-方差优化：

```
max_w  w'μ − λ·w'Σw     s.t. Σw = 1, 0 ≤ w ≤ cap
```

Σ 用滚动 252 日日收益估计 + Ledoit-Wolf 式收缩（δ=0.2），μ 为标准化后的因子得分。

| 方案                  | 样本内夏普 | **样本外夏普** | 年化     | **波动** | **回撤**      | Calmar    |
| ------------------- | ----- | --------- | ------ | ------ | ----------- | --------- |
| 等权 n50（基准）          | 0.590 | **1.017** | 21.53% | 18.98% | −25.43%     | 0.847     |
| MV n50 pool100 λ=1  | 0.513 | 0.930     | 18.93% | 18.29% | **−21.56%** | 0.878     |
| MV n50 pool200 λ=3  | 0.513 | 0.932     | 18.97% | 18.29% | −21.56%     | 0.880     |
| MV n50 pool200 λ=10 | 0.512 | 0.938     | 19.11% | 18.29% | −21.56%     | **0.886** |

波动降了（18.98%→18.29%）、回撤降了（−25.43%→−21.56%），但**收益同比例下降**  
（21.53%→18.93%），**夏普仍下降**（1.017→0.938）。

**关键诊断：所有 λ 与 pool 给出几乎相同的结果。** 这说明协方差矩阵被单一市场因子主导，  
`max w'μ − λ·w'Σw` 退化成「最小方差组合」，而最小方差就是去风险 —— 仍是 1:1 交换。

### 6.4 同一个结构性事实的四次独立验证

| 尝试             | 结果                                                 |
| -------------- | -------------------------------------------------- |
| 持有现金降杠杆        | 收益与回撤同比例缩放 → **夏普/Calmar 严格不变**（算术恒等）              |
| β 目标化（换低 β 股票） | β 0.90→0.63 有效，但收益回撤 1:1 交换，**Calmar 0.828→0.723** |
| 组合层面市值/价值约束    | 市值分位精确打到 0.50，**β_SMB 一动不动是 −0.797**               |
| 风险模型优化（MV）     | **所有 λ 退化为最小方差；夏普 1.017→0.938**                    |

**根因**：组合风险由单一市场因子主导（CH-3 解释月度方差 92.7%），  
因此任何降低风险的手段都同比例降低收益。**这不是调参问题，是结构问题。**

## 八、诚实的边界声明

1. **样本外仅 3.60 年**（906 个交易日）。要在 5% 水平显著，年化夏普须 > 1.03。
2. **相位敏感性**：单相位夏普必须打折；本报告一律给出相位平均与区间。
3. **多空口径依赖融券**。A 股融券券源有限且成本高，**多空组合仅具学术意义**；  
   可实盘的是多头组合。四类经济关联因子（Cohen-Frazzini 等）的效应也集中在  
   低关注度小盘股，而 A 股可融券标的恰好偏向大盘——这是结构性的实现损耗。
4. **未建模**：跌停无法卖出（小幅高估收益）、融券成本、历史行业分类变化（用当前快照）。
5. **残余生存偏差**：Sina 通道缺 146 只早期退市股（Tushare 通道已补全，影响有限）。
6. **CH-3 的两处口径偏离**：市值用流通市值而非总市值（无总股本字段）；  
   可用时点用监管截止日而非实际公告日（偏保守）。
7. **结构性突变风险**：Cederburg et al. (2020, JFE) 的证据是任何基于历史关系的  
   叠加层都面临平均 2.37 个 Bai-Perron 断点。本报告采纳缓冲区正是因为  
   **它不依赖对未来的预测**。

## 十一、★ 第八轮：安慰剂检验（不依赖「试验次数 N」的显著性证据）

### 11.1 为什么需要一个不依赖 N 的检验

DSR（Bailey & López de Prado 2014）是多重检验校正的标准工具，但它有一个  
**实践上无法客观确定的输入**：试验次数 N 与试验夏普的方差。报告 DSR = 0.91 还是 0.94，  
取决于我声称自己认真试过多少个配置 —— **这本质上是自证的**。

**安慰剂检验绕开了这个问题。** 做法：在每个调仓日把因子得分的数值在**截面内随机打乱**  
（保留得分分布、保留股票池、保留换手与成本结构、保留组合构建规则），重跑完整策略 B=200 次，  
得到「无预测能力时」的业绩分布，再看真实策略的位置。

它回答的问题比 DSR 更直接：  
**「按我的得分选股，是否显著优于从同一股票池里随机选股？」**

### 11.2 结果（B = 200）

| 全样本夏普      | **0.669**     | 0.158  | 0.051  | 0.243 | 0.294       | **0.0000** | **+10.11** |
| 样本外夏普      | **1.017**     | 0.261  | 0.119  | 0.441 | 0.611       | **0.0000** | **+6.33**  |

| CH-4 α 全样本 | **+8.45%/年**  | −0.38% | 1.66%  | 2.34% | 4.37%       | **0.0000** | **+5.33**  |
| CH-4 α 样本外 | **+12.16%/年** | −0.71% | 3.39%  | 4.84% | 9.72%       | **0.0000** | **+3.79**  |

**五项 p 值全部为 0.0000 —— 真实策略超出全部 200 次安慰剂抽取，连最好的一次都没追上。**

**检验设计本身得到验证**：安慰剂的 CH-4 α 均值落在 **−0.38%（全样本）/ −0.71%（样本外）**，  
几乎正好为 0 —— 说明打乱得分后确实没有预测能力，零假设构造正确。

### 11.3 ★ 一个必须说清的细节

**近 24 个月，安慰剂的夏普均值是 0.957。** 也就是说，从同一股票池里**随机选 50 只**等权，  
近两年也能拿到 0.96 的夏普（与等权全市场 1.05 接近）。因此：

> **1.720 中约 0.96 来自「这两年 A 股随便找 50 只股票本来就容易赚钱」，  
> 真正的选股超额是 +0.76（z = +4.67，p < 0.005）。**

这不是坏消息 —— 它把「绝对夏普」与「可复制的选股能力」分开了。

### 11.4 与 DSR 的关系

| 检验        | 回答的问题                    | 结论                                            |
| --------- | ------------------------ | --------------------------------------------- |
| **安慰剂检验** | 按得分选股是否显著优于随机选股？         | **p < 0.005，五个指标全部通过**                        |
| **DSR**   | 给定搜索过的配置数，该夏普水平是否可能纯属运气？ | 近 24 月 **0.9084 (N=334) / 0.9416 (N=50)**，差一点 |

**DSR 的弱点在于它需要声明「试过多少个配置」—— 这个输入是自证的。  
安慰剂检验不需要该输入，是非参数、设计驱动的，因此本报告把它作为主判据，DSR 作为对照。**

## 十二、★ 第九轮：多重检验校正的规范化（按策略族 + 逐相位下界）

### 12.1 此前 DSR 计算的两个方法论错误

**错误一：试验分布被污染。** 首版用 `glob("*.json")` 通配收集试验夏普，混入了  
① **基准指数**的夏普（沪深300 近 3 个月 −2.645）与  
② **短窗口读数**（多空 近 3 个月 5.51、近 24 个月 0.10）。  
后者是**同一策略在不同窗口上的读数**，不是「试过的不同策略」，却把多空族方差  
从 0.037 抬到 **1.039**，门槛 SR0 被抬到 2.554，DSR 直接归零。

**错误二：分类过窄（方向相反）。** 修正污染时改用键名白名单，要求含「多头/long」，  
但 `v2_grid.json` / `v2_tune.json` 的键形如 `"F17 n=15"`、`"F17 n=50 buffer=0.3"` ——  
它们**全部**调用 `make_weights(side="long")`，是实实在在的多头试验，却被漏掉。  
这使 N 偏小、方差偏小，**DSR 被高估**（与错误一方向相反）。

**正确做法**：试验集 =「一个不同的策略配置在同一评价窗口上的样本外夏普」。  
排除基准与子窗口读数；未显式标注的计为多头。

## 十三、★ 第十轮：业务相似度联动因子（Lee et al. 2019 代理）—— 否定

### 13.1 为什么做这个

这是**唯一一个还能用现有数据构造的、有 JFE 论文支撑的联动因子**：

Lee, Sun, Wang & Zhang (2019, JFE 132(3)), "Technological Links and Predictable Returns"：  
用**专利类别分布重叠**构建技术联动网络，等权多空 **117bp/月 (t=5.47) = 14.1%/年**，  
Fama-MacBeth 系数 0.643 (t=4.18)，对规模/BM/盈利/资产增长/R\&D/反转/动量  
以及**行业动量**均稳健。关键设计：TECH 加权 1.17% > 等权 1.07% > 市值加权 0.39%。

我们没有专利数据，但有 tushare `stock_company` 的 **`main_business`（主营业务描述）**。  
用它计算**字符二元组余弦相似度**作为技术关联的代理：

```
sim(i,j) = |Bg(i) ∩ Bg(j)| / sqrt(|Bg(i)|·|Bg(j)|)
```

每家股票取相似度最高的 20 家（剔除自身）行归一化，信号 = 联动同伴过去 21 日均值收益。

### 13.2 结果：IC 精确为零

| 因子                   | 样本内 IC      | t      | 样本外 IC      | t      | 与既有因子相关                                           |
| -------------------- | ----------- | ------ | ----------- | ------ | ------------------------------------------------- |
| **BIZ_LINK**         | **−0.0005** | −0.14  | **−0.0071** | −0.98  | COMMOVE −0.006 / LEAD_LAG +0.002 / IND_MOM +0.000 |
| **BIZ_LINK_X**（剔同行业） | **+0.0004** | +0.14  | −0.0050     | −0.95  | 同上                                                |
| *对照* COMMOVE         | *+0.0518*   | *9.53* | *+0.0555*   | *6.11* | —                                                 |
| *对照* GEO_LINK        | *+0.0124*   | *4.85* | *+0.0110*   | *2.17* | —                                                 |

组合层面同样无增量（多头 OOS 夏普 0.859 → 0.804）。

### 13.3 ★ 为什么这个否定结论比正面结果更有力

数据源只提供**当前**主营业务描述。用它定义 2010 年的联动网络，等于用**后来才披露的  
业务调整**去构建当时的网络 —— 这是一个**真实的前视优势**。

> **即使占了这个前视便宜，该因子的 IC 仍然精确为零。**

也就是说：若改用严格时点文本（历年年报的主营业务段落）重建，结果只会**更差**。  
因此这个否定结论**不需要再做时点复核即可成立**。

### 13.4 累计的新增因子检验记录（全部无组合增量）

| 因子           | 独立 IC（样本内/样本外）     | 与既有因子相关                 | 组合增量            |
| ------------ | ------------------ | ----------------------- | --------------- |
| CGO / CGO_R  | 0.047 / 0.035      | 与 MAX5 相关 **0.44**      | 无（后被 CH-3 完全解释） |
| ABN_TURN     | 0.058 / 0.070      | 与 TURN 同族               | 无               |
| VTURN        | 0.043 / 0.045      | 与 TURN 同族               | 无               |
| **GEO_LINK** | 0.012 / 0.011      | **+0.011 ~ +0.047（正交）** | 无（IC 太低，被稀释）    |
| **BIZ_LINK** | **0.000 / −0.007** | **≈0（完全正交）**            | 无（无信号）          |

**规律**：IC 高但与既有因子同族 → 无增量；与既有因子正交但 IC 低 → 也无增量。  
**只有「既正交、IC 又够高」的因子才能带来增量，而在现有数据源下我没有找到这样的因子。**

## 十四、如果要继续，唯一有意义的方向

**缺口已量化为「约 3.3pp 的年化 alpha」**，对应以下三条路径（按可行性排序）：

1. **引入全新信息源**（唯一可能带来质变）
   - **投入产出表**（国家统计局，约 149 部门）→ 复现 Menzly-Ozbas 的行业纵向联动  
     （实测 8.7%/年、因子模型 alpha 6.9%/年），这是四类经济关联网络中**唯一能保留经济识别性**的
   - **总部城市数据**（tushare `stock_company` 一次拉取即可）→ 复现 Parsons et al. (2020, RFS)  
     的地理 lead-lag（42bp/月, t=3.65），注意其「信号等权、交易市值加权」口径
   - **北向资金 / 融资融券余额**（若能接入 Wind 或提高 tushare 积分）
2. **降低 DSR 门槛的正确方式**（不是调参）
   - 把配置空间收敛到少数几个有**先验理由**的方案，并把选择规则事前固定下来。  
     本轮累积的 312 个配置抬高了自己要跨的门槛——这本身是多重检验的代价，  
     诚实做法是减少试验而非放宽门槛。
3. **接受现有水平，换产品形态**
   - 以 **CH-4 α +12.86%/年（t=4.29）** 为核心卖点，多头组合夏普 1.017、  
     相对中证全指超额约 14pp/年，作为「高 α 的 beta 产品」是成立的；
   - 或走多空路线（夏普 1.326、回撤 −12.66%），但需先解决融券券源与成本。
