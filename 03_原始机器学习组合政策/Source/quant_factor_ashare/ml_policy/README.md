# ml_policy — A股关系增强的非线性组合策略（实现）

把 `quant_factor_ashare` 的线性等权打分改造为**直接学习组合权重**的非线性策略。
模型的输出是目标权重（含现金），用**扣费后日净值的对数增长**训练。

规格来源：`workspace/user_home/Documents/Review/2026-10-16/new-chat/outputs/ashare_portfolio_policy_v1.json`
（14 篇顶刊研读记录见同目录 HTML）。本目录是该规格的代码实现。

## 目录结构

```
qlp/
  weights.py     有界权重代数：带上下限的单纯形投影、部分调整、不交易带
  execution.py   硬执行器：目标权重 -> 真实账本（费用/印花税/整手/容量/冻结持仓）
  data.py        点时数据层：股票池、ST/停牌/涨跌停过滤、复权价矩阵（带缓存）
  relations.py   联动关系图：过去 N 日市场残差收益的正相关邻居，严格时点
  features.py    截面特征：多窗口收益/波动/流动性，截面秩映射
tests/
  test_execution.py   13 项执行器与权重代数测试（合成行情，无需行情数据）
  test_relations.py   6 项关系图测试（含前视防护）
artifacts/
  prep_arrays.npz     缓存的数据准备数组（约 1.1 GB）
```

## 已实现并验证的部分

### 硬执行器（`qlp/execution.py`）

关键约定，均由测试锁定：

| 约定 | 含义 |
|---|---|
| 决策与执行分离 | 第 t 日收盘形成的目标，在第 t+1 日开盘执行；非决策日不交易 |
| 部分调整 | 默认向目标移动 50%，而不是直接跳到目标 |
| 不交易带 | 目标与现状的净值差小于阈值时不动（默认 0.25% 净值） |
| 单股上限 | 目标形成时 3% 净值；由涨跌停/停牌造成的实际超限如实记录 |
| 整手与费用 | 100 股整数手；佣金（含最低 5 元）、滑点、卖出印花税 |
| 印花税历史 | 2023-08-28 前 0.1%，之后 0.05% |
| 容量约束 | 使用**滞后**的成交额作为容量代理，参与率默认 1% |
| 拒单处理 | 无法成交的委托作废，持仓保留并计入风险，不假装成交 |
| 卖出资金 | 卖出确认的资金才可用于买入，同一次开盘不占用未确认的卖出款 |
| 缺价处理 | 缺收盘价时按最后已知价记账并累计“陈旧”天数；超限默认报错停止 |
| 现金约束 | 任何时点现金不为负，权重合计恒为 1 |

### 数据层（`qlp/data.py`）

- 面板 13,408,542 行，2010-01-04 至 2026-09-28，5,221 个证券。
- 股票池：过去 60 日成交额排名前 1000、上市满 252 个交易日、剔除当时 ST 与停牌。
- 涨跌停规则按板块与时间区分：主板 10%、创业板 2020-08-24 起 20%、科创板 20%、北交所 30%、ST 5%。
- 一次构建后缓存到 `artifacts/prep_arrays.npz`（构建约 167 秒，重载约 5 秒）。

### 联动关系（`qlp/relations.py`）

- 先剔除当日截面均值得到市场残差收益，再做相关，避免把大盘共同波动当成“联动”。
- 只用形成日之前的 120 个交易日，最少 80 个有效观测；每股最多 10 个正相关邻居。
- 边权为归一化的正相关系数；观测不足的股票标记为无效，而不是填零向量。

## 已知限制（必须与结论一起报告）

1. **股票池存在幸存者偏差风险。** 面板 5,221 个证券少于审计报告指出的 5,843 个，
   有 270 个沪深代码未进入面板。用今天可见的证券序列回看历史，不能声称无偏。
2. **没有历史退市处置。** 为固定张量规模，实现使用一个固定的回溯股票集合；
   这削弱了“当时可投资集合”的严格性。
3. **涨跌停是代理判定。** 用“一字板且幅度等于该板块涨跌幅”识别无法成交，
   精确判定需要交易所每日公布的价格上下限。
4. **成交量不能代替开盘时的可成交深度。** ADV 参与率只是容量代理。
5. **2023 年以后的历史已被反复使用**，属于重复验证区间，不是独立样本外。
