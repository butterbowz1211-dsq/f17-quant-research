# 直接权重政策网络：设计、协议与结果

本文只记录可以复核的东西：数据怎么变成输入、模型是什么、钱是怎么算出来的，以及结果。
所有业绩数字来自硬撮合引擎；训练损失从不作为业绩汇报。

## 1. 模型

### 1.1 一句话

把"因子 → 预期收益 → 组合优化"这三步合并成一个网络，直接输出每只股票占净值的权重，
现金作为一个对等节点参与竞争，因此仓位高低由模型自己决定。

### 1.2 结构

```
输入 x_i (6F+10 维)
   → Linear(...,32) → ReLU → Dropout
   → Linear(32,16) → ReLU → Dropout
   → Linear(16,1) = z_i
   → 与现金 logit 拼接 → 除以温度 → softmax → 权重 (含现金)
```

编码器在股票之间共享，所以参数量与横截面规模无关（F=10 时约 2.5k 参数）；每只股票走同一
张映射，横截面上的差异全部来自输入差异。

### 1.3 输入（F 个因子，共 6F+10 列）

| 块 | 列数 | 内容 |
|---|---|---|
| own 排序值 | F | 5 个回看窗口的收益、2 个波动、Amihud 非流动性、20 日最大单日收益、换手率 |
| own 缺失标记 | F | 该因子当日是否缺失 |
| peer 当期排序值 | F | 图邻居的边权加权均值（当期） |
| peer 当期缺失率 | F | 邻居中该因子缺失的比例 |
| peer 滞后排序值 | F | 同上，滞后 20 个交易日 |
| peer 滞后缺失率 | F | 同上 |
| peer 图有效性 | 1 | 该股票当日是否有可用图 |
| 市场状态 | 6 | 5/20/60 日等权市场收益、20 日波动、横截面离散度、可交易家数 |
| 账户状态 | 3 | 现金权重、距上次决策天数、持仓家数对数 |

横截面因子按当日 rank 映射到 [-1,1]（把峰度从最高 75.5 压到 1.80，消除极端值主导）；
市场/账户块只在训练切片上拟合均值方差后冻结。

### 1.4 邻居图

每个决策日重建一次：取严格在该日之前的 120 个交易日，对市场残差收益求相关，按行取
正相关的 top-10 作为邻居，边权按相关系数归一。邻居被限制在当日的点时股票池内——
买不到的邻居不是可交易的联动。

### 1.5 持股数怎么控制

- 温度：softmax 前统一除以 T，T 从 1.0 线性退火到 0.1，持仓广度随之收缩；
- `top_k`：保留最大的 K 个权重（含现金）后重新归一，用直通估计器让被丢弃的股票仍能
  拿到梯度，否则它们永远回不来；
- 单票上限 3%，训练用可微版本、执行用硬投影，两者可行集相同。

## 2. 协议

- 扩窗：6 年训练 / 2 年验证 / 1 年测试，锚定在股票池可用的首年（2013）；
- **未污染样本外只有 2021（fold0）与 2022（fold1）**；2023 年及以后已在此前的工作中被用来
  挑因子和参数，只能当探索；
- 早停只看验证期的代理信息比；测试集只在最后跑一次；
- 三个随机种子在**目标权重层**平均，然后只跑一次账本；如果对每个种子的净值分别回测再平均，
  成本会被重复计提；
- 所有业绩来自 `qlp/execution.run_target_weight_engine`：整手取整、涨跌停不可成交、停牌、
  1% 成交量参与上限、佣金（含最低 5 元）、印花税（2023-08-28 前后不同）、双向滑点 10bp；
- 训练用的代理成本是单边 25bp，**高于**引擎全成本（约 10+2.5+卖出印花税 5bp），偏保守。

## 4. 已知局限

1. 数据只有 5221 只证券，原始池 5843 只，缺失的 270 只退市股会让生存偏差偏乐观；
2. 无历史行业分类与指数成分股历史，因此无法做行业中性化，只能把行业暴露留给模型自己处理；
3. 涨跌停判定是代理（一字板 + 涨跌幅达到板块上限），不是交易所公布的限价；
4. 验证期只有约 23 个决策点，早停的噪声不小；
5. 训练期账户状态用中性先验，真实持仓路径只在硬引擎里产生。
